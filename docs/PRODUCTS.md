# 产品展示

产品独立于 GitHub 仓库。一个产品可以没有仓库，也可以链接多个仓库；代码仓库数量、Star 和 Fork 不参与产品计数。已有 `homepage_projects` 与 GitHub 快照继续保留，不自动变为产品。

公开入口为 `/products` 和 `/products/{slug}`。公开列表优先显示勾选推荐的产品，每组再按排序值、ID 排列；只有公开且未删除的产品可见。`?product={slug}` 可以选择列表中的产品，其规范链接指向独立详情页。站长登录不会扩大公开页面、公开 API 或 sitemap 的可见范围。

迁移 `0025_products.sql` 仅添加已确认存在的 Painter 产品，平台为 Web，主入口为站内 `/`。没有推测下载地址、源代码地址、版本号、用户量或安装量。迁移只执行一次，不会在重启时恢复已编辑、撤回或删除的种子内容。

此记录使用不可修改的内建标识提供原有 Painter 图标和真实页面截图作为默认资源。其他产品不会因为名称或 slug 相似而得到这些资源。后台上传图标或封面后优先使用上传图片；清除上传引用会恢复内建默认资源。

## 管理与 API

`/studio/products` 供站长管理。管理 API 均要求 owner；写入沿用会话、CSRF、`Idempotency-Key`、审计和事务机制。更新及删除还必须提供带引号的 `If-Match` 版本，冲突返回 409。版本表示编辑修订，不代表产品发行版本。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/products` | 公开产品目录与真实数量 |
| GET | `/api/v1/products/{slug}` | 当前公开的完整介绍 |
| GET / POST | `/api/v1/admin/products` | 管理目录 / 新建 |
| GET / PUT / DELETE | `/api/v1/admin/products/{id}` | 读取完整编辑内容 / 更新 / 软删除 |

目录支持 `state`、`platform`、`q` 过滤。`total` 与各状态数量始终统计全部公开产品；`result_count` 表示当前过滤结果数量。管理目录不加载 Markdown 和 HTML，编辑前读取单条完整内容。

字段包括名称、稳定 slug、简介、Markdown、图标、封面、截图顺序、平台、生命周期状态、公开开关、精选、排序、主动作、文档地址和仓库链接。状态为 `development`、`available`、`archived`，与是否公开分开。每个产品最多 12 个平台、12 张截图和 12 个仓库，活动产品总数最多 200。

slug 创建后固定，改名不会改变公开地址；软删除后 slug 仍保留，以免旧地址指向无关产品。产品编辑保存后直接更新公开介绍；需要先私下整理时应撤回公开，再保存和重新公开。

## 内容与媒体边界

Markdown 使用文章的统一渲染和清理流程。图片先上传为媒体资源，再保存其 ID；正文图片也必须使用 `/media/{id}`。新引用只能附加当前站长自己上传且已就绪的有效图片；已有引用可由其他站长保留。

`product_media` 同时保护图标、封面、截图和正文图片，供删除检查、垃圾回收和公开读取授权使用。未公开的产品不授予匿名访问图片的权限；撤回立即收回由该产品授予的公开访问。其他公开内容仍引用同一图片时，该图片继续公开。删除产品只释放其引用，不删除图片或其他内容的引用。

产品中的 HTTP(S) 链接只作为浏览器目标，服务端不会读取它们。站内主入口和文档路径也可使用；协议相对地址、账号密码、控制字符、脚本和数据 URL 被拒绝。

## 验证

产品测试覆盖权限、CSRF、重试幂等性、版本冲突、稳定地址、真实计数、过滤、草稿隔离、图片归属、撤回、共享引用、垃圾回收与 SSR/sitemap。数据库集成测试只读取显式的 `PAINTER_TEST_DATABASE_URL`，并为每项测试创建和删除独立 PostgreSQL 18 测试库。
