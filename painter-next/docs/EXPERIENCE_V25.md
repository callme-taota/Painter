# V25：首页浮动工具的液态玻璃

首页右侧工具在游戏与音乐影像上呈现液态玻璃，离开影像时平滑恢复原有纸面、边线与小阴影。沿用既有中性界面、工具尺寸、位置、图标与操作；这是首页局部材质扩展。

**当前状态：已更新局域网入口。候选75/75项只读检查通过，10张候选图获独立 SHIP；正式33/33项只读检查通过。**

## 材质与滚动

强度依据工具栏所在位置实际被影像覆盖的面积计算，包含游戏开合遮罩的边界与圆角。章节进入视口而影像尚未到达工具栏时，仍保留实色；相邻游戏与唱片墙按覆盖并集计算，交接时连续，反向滚动也同步还原。

玻璃层使用真实背景模糊、薄内缘光与主题对应的半透明底色。覆盖强度从0到1时，模糊为0–24px、饱和度为1–1.65，材质以220ms缓动；原有纸面与边线随之淡出。只测量和过滤小范围工具栏，滚动事件按需安排单帧，没有空闲动画循环或额外远程请求。首次进入时在展示墙完成遮罩布局后重新核对覆盖。

实现见 [homeControlGlass.ts](../web/frontend/src/homeControlGlass.ts)、[homeControlGlass.css](../web/frontend/src/homeControlGlass.css)；授权边界见[局部表面记录](../web/.impeccable/surfaces/home-controls-v25.md)。

## 使用与回退

主题菜单仍为实色，文字、图标、焦点、点击目标与原生链接行为沿用原实现。关闭透明效果、系统减少透明度或提高对比度时恢复原有实色工具；无 JavaScript、不支持所需 CSS 能力时也保留原样。减少动态效果移除材质缓动，覆盖位置仍准确。其他页面不启用此增强。

## 验证与边界

[候选报告](../tests/artifacts/v25/home-glass-browser-report.json)记录75项通过，覆盖浅色/深色、1440×900与390×844视口、进入/退出/反向滚动、游戏遮罩初次到达、游戏音乐连续交接、菜单/焦点、偏好与静态回退及其他路由。10张候选图包含8张视口图和2张原尺寸工具栏细节，[独立复审](../tests/artifacts/v25/finish-review.md)结论为 SHIP；[单次检测](../tests/artifacts/v25/detector.json)结果为`[]`。

证据来自当前安装的 Chrome；减少透明度与高对比度通过浏览器模拟，不支持能力以模拟断言验证。390px是浏览器视口，未测试实体手机或其他浏览器。独立视觉裁决只覆盖上述候选图。
