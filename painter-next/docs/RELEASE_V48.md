# V48：移除手机玻璃的滚动追赶

2026-11-13 22:33:46（Asia/Shanghai）已上线，源码提交 `cfe10c6`。

## 问题与修复

用户实际手机反馈 V47 比原来更卡，页面已经划过，玻璃中的背景副本才跟上。V47 的静态折射 A/B 与静止开销检查没有覆盖这条滚动体验，不能作为流畅性的证明。

旧实现收到 scroll 后，在主线程 RAF 中扫描公共图片与祖先几何、更新镜像位置 / 裁切，再绘制 SVG 位移。这条时间线无法与浏览器合成滚动保持原子同步，负载高时会有追赶；新进入图片还可能等待副本加载 / 解码。

本轮删除整个 `liquidGlassMedia.ts` 管线，包括图片副本、源树观察器、滚动扫描、300ms 头栏追随、独立 OBB 滤镜图、地图解码和60 / 250ms换ID定时器。手机不再生成 SVG 位移图或法线 PNG；只用控件表面的浏览器原生 backdrop 模糊、底色和 CSS 边缘高光。桌面原有滤镜保留。

同时移除搜索时对整个主区域 / 工作台的普通 CSS filter 模糊，避免大面积离屏绘制；手机全屏搜索使用更稳的 94% 底色及原生 backdrop 回退，保留搜索、输入、结果、返回和主题行为。

这次不通过缩短 JS 动画时间继续追赶页面；手机的模拟图片折射已经撤销。不是所有网页内容都能在低开销下得到 iOS 原生 Liquid Glass 等价效果。
