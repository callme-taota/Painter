# V9 工作台导航层级

Mode: Operate. 本轮优化栏目归属和两层导航，保留V8侧栏宽度、Logo、主题、字体与所有业务能力；不新增数据表或权限。

## Direction contract

THESIS: 左侧先选择职责分区，再进入具体页面；写文章是内容页动作，个人关系和上传文件维持个人范围。

OWN-WORLD: 沿用纸墨蓝、分组SVG、44px入口与细线。一级为可展开按钮，二级缩进显示，当前叶子为唯一蓝色选中项；位置提示连接导航与任务。

STORY: 内容管理/数据与运维/站点管理/个人空间 → 二级入口 → 页面操作。按真实role与资源范围过滤后移除空组；reader只保留个人空间。

FIRST VIEWPORT: 默认展开当前分区，其余收起；用户可展开其他组，偏好按账号存于本标签会话。当前页面、编辑子页、设置hash和粉丝别名均显示准确位置。底部账户/主题保持原样。

FORM: 用户指定的两层结构，code-led existing-world refinement，无新视觉世界或概念抽签。桌面站点设置从侧栏选择子项；移动端抽屉保持两层，保留页内设置tabs共享同一hash状态。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
