# V37：搜索的 Liquid Glass 材质

2026-11-08。按用户要求，把搜索接入现有顶部栏与右侧工具使用的玻璃渲染层，保留 Raycast 布局与既有搜索合同。

## 展示与实现

- 全局搜索采用一块稳定的玻璃面板：底图模糊、圆角边缘折射、高光与主题染色；前景文字不参与过滤。输入、状态与底栏固定，仅建议列表内部滚动。
- 完整搜索页的关键词框、标签/排序触发器及其浮层共用材质。结果正文仍是正常阅读页面。浮层加强底图模糊，避免页面大字透入菜单。
- 手机提交、关闭按钮均有 44×44px 触控范围。保留箭头选择、Enter、Esc、Ctrl/Command+K、斜杠、中文输入合成、取消旧请求、建议故障回退和关闭后还焦点。
- 使用 `data-search-glass` 显式注册到现有 `liquidGlass.ts`；新增 `searchGlass.css`，不引入依赖、WebGL 或持续动画循环。隐藏弹窗/浮层打开、列表高度变化与窗口变化均重新测量。
- Chromium 保留折射路径；其他渲染器使用 CSS 模糊/高光。减少透明度、提高对比度、强制色与不支持底图过滤时回退到实色。无脚本时保留完整搜索页原生 GET 表单与语义输入。
- 蓝色完整搜索链接与快捷键文字针对最不利明暗底图校验：链接对比度分别 4.955:1、4.631:1；快捷键使用实色前景。

## 验证与边界

TypeScript/Vite、Linux Go 生产构建、相关搜索/导航/首页文案测试通过。正式页面只读浏览器验收 127/127 通过，无运行错误或非预期同源 HTTP 错误；17 张正式截图实际查看，包含桌面/手机明暗主题、真实游戏背景、标签浮层、长建议列表与各回退状态。

正式数据库没有公开文章。真实 GET 覆盖站内入口、空搜索、筛选与导航；成功的长建议、503 与竞态仅通过浏览器拦截 GET 响应模拟，报告已分开标记。两条 503 为预期模拟结果。全部浏览器验收阻断非 GET/HEAD 请求，不创建文章或活动，不修改站点配置。UA 模糊分支与强制色使用 Chromium 验证，不代表实体手机、软件键盘或 Safari 实测。原生 Tab 可先进入浏览器栏，但不会落入弹窗后的页面控件；此行为与修改前一致。

检测器无法解析 Go 模板中的动态样式链接 `{{.}}`，因此其原始模板预览的黑色/字号告警不能作为运行页面结论；已按实际构建页面核对。
