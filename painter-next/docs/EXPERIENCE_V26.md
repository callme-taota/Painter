# V26：首页连续叙事

首页沿既有 Painter 纸页继续向下：个人介绍 → 三个真实 GitHub 项目 → 真实发布日历 → 可选照片 → 唱片墙 → 从一格唱片大小展开的游戏影像 → 收束 → 最近文章。文章成为最后的阅读邀请，页脚仍在其后；这一顺序通过站长保存的首页配置启用。

**当前状态：已更新局域网，并通过正常站长 API 启用请求的首页顺序与收束阅读邀请。候选功能129/129项、收尾修正25/25项、10张替换截图的13/13道捕获检查及正式只读核验51/51项通过。独立复审为候选范围内的限定 SHIP。**

## 连续手势与配置

介绍纸页收向第一个真实项目卡片；项目区随后以小纸片落向当前可见的真实日历格。日历沿用首次公开发布时间、来源、时区、范围和撤回/删除规则，不把 GitHub 提交或装饰格子算成发布记录。

唱片墙选择并测量一个实际唱片格，以它的四边位置作为游戏窗口的非对称起点。窗口中从一开始就是真实游戏影像，随后展开至全屏、依次展示最多五款游戏，最后退回纸面。游戏身份、时长、Steam 链接和完整游戏库入口沿用保存的数据。退出时先完成文字与控件淡出，再收小影像窗口；原生游戏链接或章节按钮持有焦点时保留对应完整画面与可用控件，焦点离开后恢复当前滚动位置。反向滚动可还原这些过渡。

服务端先按已保存顺序筛除禁用、零数量和无内容区块，再分组实际相邻的区块。工作手势只包住相邻且顺序为介绍 → 项目 → 日历的三段；唱片 → 游戏和原有游戏 → 唱片均保留自己的顺序。可见分隔区块阻断分组，隐藏或空区块不留下占位舞台。照片仍为可选的独立内容。

无 JavaScript、减少动态效果和站长关闭动态效果时，原生服务端内容与链接按普通文档流阅读。增强使用原生滚动与按需动画帧，不拦截滚轮，也没有空闲渲染循环。V25 右侧玻璃工具继续依据真实影像覆盖，现已读取游戏遮罩的四个独立边界；离开影像恢复实色，原有减少透明度、提高对比度等回退保留。

实现见 [homeStory.ts](../web/frontend/src/homeStory.ts)、[homeWorkJourney.ts](../web/frontend/src/homeWorkJourney.ts)、[homeShowcase.ts](../web/frontend/src/homeShowcase.ts)、[homeControlGlass.ts](../web/frontend/src/homeControlGlass.ts)及[服务端分组](../internal/app/homepage_render.go)。局部范围见[表面记录](../web/.impeccable/surfaces/home-journey-v26.md)。本轮没有新建视觉体系、schema 迁移、内容导入或已发布正文的全量重渲染。

[捕获记录](../tests/artifacts/v26/capture-manifest.json)记录13项检查和同名替换的10张截图；[独立复审](../tests/artifacts/v26/finish-review.md)保留初次完整审查历史，最终 SHIP 限于该范围内 F1、F2 均已解决。[唯一一次检测](../tests/artifacts/v26/detector.json)为零项主要发现、一个既有未渲染模板 `h1` 的黑色文字 advisory，结果并非 `[]`；未为本轮重新运行检测或修改既有 token。

候选观测为三个仓库、13次发布/2天、五个游戏场景和24张唱片封面；候选照片仅供隔离环境验收。正式数据保留三个公开仓库、2次发布/1天、112款可见游戏、291张专辑，其中首页最多五款游戏与24张封面。候选数量和照片不代表正式数据，也不导入正式库。访客使用本地保存的项目与内容快照；官方图片仍可能从远端加载。外部原生目的链接以本地响应核对 URL，未据此宣称完成外站交互；390px为 Chrome 视口，未验证实体触屏设备或 Safari。

前端与 Go 构建通过；[六组定向 Go 测试](../tests/artifacts/v26/final-targeted-go.log)通过，包含真实 PostgreSQL 的服务端顺序、显隐、空区块和旧六区块配置检查。原共享测试集群创建临时库时因 `template0`/`postgres` 所涉 catalog 文件缺失失败，见[原始失败日志](../tests/artifacts/v26/home-grouping-tests-old-cluster-failure.log)。本轮改用独立 PostgreSQL 18 测试集群（端口65441），测试后已停止且无遗留测试库；没有修复或宣称原共享集群整体健康。正式业务 HTTP 当时仍返回200，这只说明已观测业务请求可用。

正式入口为 <http://192.168.2.209:18080>。[发布记录](../tests/artifacts/v26/promotion.json)确认先仅替换应用二进制，58张表逐表行摘要、媒体、环境配置与迁移账本均一致，schema仍为20；没有迁移、恢复数据库或复制候选数据。

随后[正常站长 API 保存记录](../tests/artifacts/v26/formal-order-change.json)确认仅将首页顺序改为 `intro → projects → activity → photos → music → steam → closing → articles`，并更新收束标题、“继续阅读”文案与 `#home-writing` 链接。提供方身份、Steam 同步、显隐、数量上限和其他配置均保留。二进制替换时的全表一致校验与随后这次有意配置写入分开记录。

[正式只读核验](../tests/artifacts/v26/lan-smoke.json)51项通过，覆盖1440、390及320宽度的实际渲染顺序、三个项目、真实发布总数、纸页/日期交接、唱片格展开、全屏游戏与玻璃、退出实色恢复、外观菜单、末尾阅读锚点、无横向溢出、当前资源和就绪状态；运行错误与业务写入均为零。记录包含四张正式运行截图；这次正式核验与候选完整矩阵、候选独立视觉裁决分别记录，不将候选 SHIP 扩展为对正式截图的独立复审。
