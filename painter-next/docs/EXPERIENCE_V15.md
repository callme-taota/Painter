## 页面与交互

- 顶部为“文章 / 片语 / 搜索”。友链随页面开关显示在页脚；首页和关于页不再重复放友链入口。
- 移除独立标签导航与首页标签区域。旧 `/tags` 永久跳转 `/search`；文章标签、搜索建议中的标签进入 `/search?tag_id=…`。
- 搜索页先呈现关键词输入和搜索按钮，下方是紧凑的标签、排序与重置筛选。
- 标签可搜索、多选、清空和逐个移除；最多20个，匹配任一所选标签。选择变化后明确提示点击搜索，不混淆当前结果与未提交条件。
- 可以只选标签或只按作者查询。关键词仍为规范化子串、多关键词 AND 匹配。支持相关性和最近发布排序，修复长关键词按时间排序时原有的SQL参数绑定错误。
- 多标签通过重复 `tag_id` 参数传递；去重排序后的集合参与分页作用域，交换顺序不影响游标，改变集合会拒绝旧游标。只查询公开投影，不读取未发布草稿。
- 选择面板、复选框与单选框使用站点样式，保留语义、Tab/Space、Escape和焦点反馈。站内源模板/组件已没有原生 `<select>`。原有后台自定义单选、编辑器标签组件继续使用。
- 320px结果使用完整文字列，避免封面挤压标题与摘要。其他尺寸保留封面。无JavaScript时，原生表单和details仍能筛选提交。

实现主要在 `internal/app/search.go`、`content.go`、`web.go`、`web/templates/page.html` 和 `web/frontend/src/searchFilters.ts`、`searchPage.css`。

## 部署与维护

```bash
./install.sh
./maintain.sh
./maintain.sh doctor
./maintain.sh backup
./maintain.sh backups
./maintain.sh verify-backup --backup 备份目录名
```

工具管理标准Compose部署：单Go程序 + PostgreSQL18；Node/Go仅用于构建。配置与业务数据使用持久目录/卷，升级先备份，失败保留真实退出码。完整备份包含数据库、媒体、原始私有配置和Compose快照。恢复验证使用独立临时数据库，不覆盖运行数据库。源码升级不自动拉Git，镜像升级必须指定真实版本。

当前LAN开发实例仍使用原systemd服务，并非Compose部署；`maintain.sh`不会接管它。当前机器没有Docker daemon，64项部署检查采用严格Docker替身，真实镜像构建、容器联网与容器内恢复尚未认证。目标服务器的完整使用步骤见[部署维护工具](deployment-tool.md)。

## CLI 与 AI 接入

同一二进制提供 `painter admin`、`painter mcp`。远程客户端不需要数据库配置或服务器密钥。

支持管理员登录/退出、身份查询、全站文章分页/读取/状态、创建/完整保存草稿、发布/撤回、标签分页/创建。通过MCP stdio接入AI客户端，默认4个只读工具；显式 `--allow-write` 后为9个工具。不内置模型对话、供应商API Key或额外服务。

客户端读取正常登录接口生成的owner会话，私有配置以0600原子保存。每次调用刷新会话权限与CSRF；服务器的Require、Write、Replay在现有权限校验点收紧管理员工具权限，写事务和幂等重放都在锁内重查角色。服务端声明 `admin_tools_version:1`，客户端拒绝不支持约束的旧服务器。普通账号不能使用管理工具。

写入继续走HTTP业务接口及其渲染消毒、引用验证、审计、修订快照、搜索投影和事件事务。保存/发布明确传入文章版本与草稿版本，写操作要求稳定幂等键；失败不自动覆盖版本冲突。完整保存快照保留封面、日期、媒体和标签，避免同一幂等键重试时隐式重读导致请求内容变化。

登录、操作示例及MCP配置见[管理员 CLI / MCP 文档](admin-cli.md)。
