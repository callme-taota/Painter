# V17：紧凑选择控件与统一圆角

这一轮统一全站表单、选择项和相关菜单的尺寸与圆角。数据、接口和schema不变，继续使用原有Go/PostgreSQL架构。

## 尺寸规则

| 场景 | 桌面细指针 | 720px以内或粗指针 |
| --- | --- | --- |
| 常规控件、单选与菜单行 | 36px | 44px |
| 标签栏/分段控件内部 | 28px | 36px |
| 选择项文字 | 13px / 20px行高 | 13px / 20px行高 |
| 常规可编辑输入文字 | 14px / 20px行高 | 16px / 20px行高 |

复合搜索输入的边框外壳遵循36/44px，内部无边框输入减去2px；内嵌按钮遵循28/36px。编辑器标签栏不再在44px标签外叠加留白。多行内容自然增高，不裁切文字；标题、正文、Markdown和个人介绍保留阅读字号。

作者配色改为一行小色样、名称和16px单选标记，小屏两列排列；背景大预览独立保留。搜索排序说明在可用空间内与名称同排，主题和段落选择菜单使用相同密度。源码格式工具在窄屏组内横滑，避免单个“链接”挤成孤立一行；分段选择器保持外壳/内部两个尺寸层级。

## 圆角规则

- 4px：菜单选项、标签、内嵌选中项。
- 6px：常规按钮、输入、选择触发器。
- 8px：浮出菜单。
- 12px：面板、对话框和主要容器。
- 公共导航保留24px/20px，头像与radio保留圆形，分割线和下划线导航保持直边。

CSS变量集中在 `web/frontend/src/style.css`，普通样式和Vue scoped样式均引用它们。没有用全局!important强压组件。`SelectField.vue`在渲染后测量菜单自然高度并限制到视口，移除“选项数量×44px”的定位估算，支持Teleport到body或dialog。
