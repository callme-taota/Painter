# 评论与回复通知

个人空间的 `/me/notifications` 提供站内通知。首版仅覆盖文章评论与回复，不发送邮件，不为历史评论补发通知。

## 收件人与阅读

- 新评论提醒文章作者；回复同时提醒文章作者和实际被回复的人，不通知整段讨论中的其他参与者。
- 自己的操作不提醒自己。文章作者同时是回复对象时，仅收到一条「回复了你的评论」；停用的收件人不接收新通知。
- 全部／未读筛选、未读数量、手动刷新与连续加载使用当前账号的数据。追加失败保留已显示条目，重试沿用游标；刷新重新从顶部读取。
- 「查看讨论」跳转到具体评论。「标为已读」是独立操作，打开讨论不自动标记。确认写入后更新界面；未确认时允许重试，重复请求不重复扣减。
- 相关内容当前不可见时，只显示「这条讨论已不可用」，仍可标为已读。其正文、文章标题、对方资料、来源 ID 和跳转地址不返回客户端。恢复可见后可重新读取当前内容。

通知数量包含尚未标为已读的不可用条目，不等于当前可访问讨论的数量。关闭新评论功能不删除历史通知。

## 数据与接口

迁移 `0027_notifications.sql` 新增 `notifications`，保存收件人、评论引用、提醒类型、创建和已读时间，不保存文章标题、评论正文或对方资料快照。`(recipient_user_id, comment_id)` 唯一约束防止重复投递。

评论、通知和已有 outbox 事实在同一事务提交；任一步失败均回滚。现有评论幂等重试不重新投递通知，不增加队列、轮询任务或独立运行服务。

| 方法 | 路径（省略 `/api/v1`） | 行为 |
| --- | --- | --- |
| GET | `/me/notifications?filter=all\|unread` | 自己的通知，默认 20 条，最多 50 条；支持 `cursor`、`limit` |
| PUT | `/me/notifications/{id}/read` | 标记自己的通知已读；重复调用返回 204，保留首次已读时间；他人或不存在的记录返回 404 |
| GET | `/posts/{postID}/comments/{commentID}/context` | 当前公开评论的主评论与目标评论，有界读取；跨文章或不可见目标返回 404 |

通知列表返回 `viewer_id`、`filter`、`items`、`unread_count`、`has_more`、`next_cursor`。每条至少包含字符串 `id`、`kind`（`comment`／`reply`）、`created_at`、`unread`、`available`。可用来源另含 `actor`、`post_title`、最多 240 个 Unicode 码点的纯文字 `body`、字符串 `post_id`／`comment_id` 和站内 `url`。

按 `(created_at_ms, id)` 倒序，签名游标绑定账号、筛选和页大小。一次读取使用短只读一致快照，未读数量与当页投影一致；下一页重新读取当前状态，不是整个浏览过程的历史快照。

## 当前可见性与讨论定位

通知读取关联当前 `public_posts` 与评论状态。文章不公开、评论作者停用、评论／主评论／实际回复对象不可见时，返回不带来源信息的通用条目；不从草稿或历史快照取正文。

`/posts/{postID}?comment={commentID}#comment-{commentID}` 通过专门接口读取主评论与目标，无须遍历之前的评论页。回复目标较晚时只展开对应回复，并明确提示当前是通知对应的讨论。点击「查看完整讨论」移除定位参数并恢复普通连续列表；定位不可用时也能返回普通讨论。读取和写入继续遵守原有公开、回复对象、删除及权限规则。

## 身份与缓存

页面和通知 API 要求有效会话，沿用访问策略、停用、MFA、会话撤销与 CSRF 规则。页面未登录时跳转登录并保留返回地址；API 返回 401。页面、API 和页面登录跳转均为 `private, no-store`，页面声明 `noindex,nofollow`，不新增搜索或 sitemap 入口。

前端核对每次响应的账号，取消过时请求。退出、会话失效、账号变化、标签页隐藏及进入浏览器返回缓存时隐藏并清空通知；返回后重新验证身份，再重新读取。通知不写入 localStorage、IndexedDB 或服务工作线程缓存。

## 验证与部署

PostgreSQL 18 HTTP 集成测试覆盖收件人、去重、自操作抑制、幂等重放、事务失败回滚、已读隔离、CSRF、游标隔离、来源隐藏、撤回和有界定位。浏览器回归编译真实工作台与评论组件，使用全部拦截的合成 API 验证分页、失败重试、迟到响应、账号与缓存返回、双语、320／390px 交互和讨论定位；不等同于线上或真实手机验收。
