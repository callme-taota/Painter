# V20：独立动态与创作入口

本轮新增独立的短内容「动态」。文章、片语与动态各有自己的内容模型和展示方式：动态用于纯文字的即时记录，不占用文章草稿或片语条目。界面继续沿用 V18 的中性浅深色、实色表面、无衬线字体与紧凑控件。

## 内容与公开规则

- 每条动态最多 **500 个 Unicode code points**。中文、英文、空格和换行均计入；一个补充平面字符（例如单个 emoji）计一个，组合符号及组合 emoji 按组成的 code points 分别计数。计数不使用 JavaScript UTF-16 字符串长度或原生 `maxlength`。
- 纯空白内容不能保存；正文保留原有空格和换行。公开页按转义的纯文本显示，不解释 Markdown 或 HTML。
- 新建先保存草稿，再明确点击「发布动态」。修改已发布条目后，「保存草稿」只改变工作副本；点击「发布更新」才替换公开文本。
- 撤回移除公开版本并保留草稿；删除将条目从公开页面移除。已删除条目在私有管理列表中仅供查看，本轮不提供恢复或重新发布。
- 公开列表仅读取已发布内容，按首次发布时间及 ID 倒序排列。更新或再次发布不会把旧动态顶到列表最前。

500 是当前服务端上限，私有列表通过 `max_text_length` 返回给编辑器；前端字数提示跟随服务端值。保存仍由服务端校验，前端计数不代替写入约束。

## 阅读与布局

顶部导航增加「动态」，入口为 `/moments`；每条动态的时间链接通向 `/moments/{id}`。公开卡片由服务器渲染作者、头像或姓名回退、发布时间和全文，无 JavaScript 仍可阅读。

动态页提供「列表 / 双列 / 多列」三个自定义按钮。默认双列；列表使用最多760px的单列阅读区，多列在普通宽屏为三列、足够宽时为四列。720px及以下统一显示一列，但不覆盖用户原先保存的布局偏好；回到宽屏继续使用原选择。偏好只存于当前浏览器的 `painter-moment-layout`。

布局只作用于动态卡片，不改变文章列表、搜索结果或片语。网格按 DOM 顺序逐行排列，视觉和阅读顺序一致，不采用瀑布流或多栏重排。无 JavaScript 时隐藏布局按钮，保留服务器默认布局和窄屏单列。

## 后台管理与权限

内容管理 → 动态管理（作者显示「我的动态」）进入 `/studio/moments`。站长可以切换全站 / 我的范围；作者只可管理自己的动态，读者与未登录访客没有写作权限。隐藏入口不替代服务端权限校验。

列表使用服务端状态筛选和游标分页，区分全部、草稿、已发布、已删除。计数明确写作「第N页 · 本页N条」，不把当前页冒充全站总量。已发布条目的新草稿有「未发布的修改」提示。

编辑器初始为空，不自动选中第一条内容；切换条目先读取该条最新私有草稿。桌面是列表与编辑区并列，窄屏先编辑、再列表。新建入口可使用 `/studio/moments?compose=1#moment-compose` 定位并聚焦编辑框。

保存和发布为两个明确动作。切换或新建时确认未保存输入，离开页面有 `beforeunload` 保护。版本冲突保留当前输入，先读取最新草稿，再由用户选择保留输入继续编辑或确认替换为服务器内容；读取失败不覆盖输入。新建请求在结果不确定时保留幂等键及原始请求内容，重试确认后仍保留用户后来输入的新修改。这里的未保存保护不等同于文章编辑器的 IndexedDB 离线恢复。

写入复用现有会话、CSRF、版本条件与幂等约束：

| 动作 | 接口（`/api/v1` 前缀） |
| --- | --- |
| 私有分页列表 | `GET /me/moments?scope=mine\|site&status=all\|draft\|published\|deleted` |
| 读取私有草稿 | `GET /studio/moments/{id}` |
| 新建草稿 | `POST /moments`，正文 `{text}` |
| 保存草稿 | `PUT /studio/moments/{id}/draft`，正文 `{text}` |
| 发布 | `POST /studio/moments/{id}/publish` |
| 撤回 | `DELETE /studio/moments/{id}/publication` |
| 删除 | `DELETE /studio/moments/{id}` |

私有响应区分草稿 `text` 与已公开 `public_text`；公开响应仅提供已发布文本和公开作者资料，不暴露草稿或私有联系方式。

## 可选右侧创作工具

站长在站点设置 → 功能与通知 → 右侧浮动工具，为首页、文章页、其他页面分别选择「创作入口」。它只对有写作权限的站长和作者出现，提供「写文章」和「发动态」两个实际入口。

新增创作工具默认关闭，升级保留各场景原先保存的工具选择，不自动加入或重置。既有默认值继续为首页 / 其他页面的主题、回到顶部、我的账号，以及文章页的主题、回到顶部、到达底部、点赞、我的账号。动态页使用「其他页面」场景；全部取消时该场景不显示浮控。后台工作区仍不显示公开右侧工具。

## 数据链路

迁移 `0015_moments.sql` 新增 PostgreSQL `moments` 表：归属作者与不可变 ID、CAS 版本号、`draft_text`、可空 `public_text`、首次/最近发布时间、创建/更新时间及软删除时间。长度与发布/删除状态另有数据库约束，公开查询只使用不含草稿的 `public_moments` 视图；公开时间和作者排序有对应索引。

写入按现有鉴权、CSRF、策略屏障、幂等记录、版本检查和审计事务执行。草稿保存只写工作文本；发布在同一事务复制为公开快照；撤回或软删除清空公开文本。审计失败整体回滚。公开 ID 均按字符串输出，避免浏览器大整数精度丢失。本轮不增加运行时服务或数据库类型。
