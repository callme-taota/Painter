# V14：友链与页面设置

公开页 `/friends` 是与既有阅读界面一致的站点名录：衬线标题、可编辑介绍、头像 / 网站名称 / 主机名 / 简介。宽屏两列、窄屏一列，原生外链在新标签打开。入口位于首页末尾和关于页，顶部栏与页脚保持原结构，沿用非首页下滚隐藏 / 上滚出现的导航。

站长通过 **内容管理 → 友链**（`/studio/friends`）维护内容。页面有两个分区：

- **友链列表**：添加、编辑、删除、展示 / 隐藏、数字排序，支持本地搜索和自定义状态筛选。数字小的在前，同值按添加先后排列。最多500条；列表接口返回全量，不将已加载数量冒充总量。
- **页面设置**：标题、支持换行的介绍和独立开关。关闭后公开页404，首页 / 关于入口与站点地图同步移除，后台数据保留。未保存的开关只属于表单草稿，不提前改变公开预览链接或保存结果说明。

编辑器与列表宽屏分栏，手机将编辑器放在列表前。切换编辑对象或删除有明确确认，错误保留输入；版本冲突阻止旧版本继续提交，用户可明确载入最新或保留内容另存。页面离开前提示未保存内容；此表单没有宣称持久离线恢复。

头像为选填HTTP(S)地址，不通过后端代理抓取；浏览器使用无referrer、懒加载图片，成功加载后才显示，失败使用名称首字。禁用JavaScript时保留首字、完整文字及可访问原生链接。页面只展示已保存且可见的友链；不会预置虚构的真实朋友。页面访问沿用现有 `page_view.v1` 与统计关闭选项。

## 数据与接口

迁移 `0013_friend_links.sql` 新增两张PostgreSQL表，schema由12到13；没有新增数据库产品或第三方运行服务。

| 表 | 字段及职责 |
| --- | --- |
| `friend_links` | `id`；`name`（1–80字）；`url`（HTTP(S)，≤2048字节）；`description`（≤240字）；`avatar_url`（选填）；`sort_order`（-100000…100000）；`visible`；`version`；创建 / 更新时间毫秒。公开索引为可见记录的排序值与ID。 |
| `friend_link_settings` | 单行ID=1，`enabled`、`title`（1–80字）、`description`（≤400字）、`version`。迁移默认开启、标题“友链”、介绍空，不创建任何友链。 |

| 方法 / 路径 | 行为 |
| --- | --- |
| GET / POST `/api/v1/studio/friends` | 站长读取全量 / 创建，创建需要幂等键。 |
| PUT / DELETE `/api/v1/studio/friends/{id}` | 站长更新 / 删除，需要 `If-Match`；缺少版本428、冲突409。 |
| GET / PUT `/api/v1/studio/friend-settings` | 站长读取 / 保存页面设置，PUT需要 `If-Match`。 |
| GET `/friends` | 匿名SSR；公开设置和可见条目由同一SQL语句快照读取，关闭即404。 |

写入先校验站长会话、CSRF、字段和网址，再沿用既有写事务与权限锁。新增条目时锁定设置单行以串行检查500条上限；写条目、审计和创建幂等收据在同一事务提交。更新 / 删除先锁行比较版本，成功更新递增版本。设置使用独立版本，避免编辑友链与修改页面文案相互覆盖。网络重试使用原创建键，不因响应丢失再建一条。

网址拒绝userinfo、空白 / 控制字符、模糊反斜杠和非法端口，只允许绝对HTTP(S)地址；简介允许换行并规范化LF，其他控制字符仍拒绝。公开文字由模板转义，外链采用 `noopener noreferrer`；隐藏内容和关闭页面不会通过登录身份或查询参数变成公开内容。普通读者、作者没有管理权限。

全量备份继续通过pg_dump覆盖两表；旧站迁移包保持原互换格式，与现有片语相同，不额外承诺导出友链。新增审计动作 `friend.create/update/delete`，页面配置复用站点设置审计。
