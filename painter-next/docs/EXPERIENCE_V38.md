# V38：相同行列的中央矩阵直接放大

2026-11-08。修正 V36 中央取点仍不规则的问题。上一版以距离选最近 25 格，桌面来源是 1/4/5/5/5/4/1 的轮廓；手机虽然来源为 5×5，映射到两列唱片墙时仍会交叉错排。因此本轮同时修正来源选区与前后网格对应关系。

## 实现

- 按真实唱片墙首屏可见的完整行，确定参与放大的列数与行数；按视觉位置排序，而非按 DOM 顺序截取封面。
- 在当前可见日期中选择最靠近中央的连续完整矩形，保持前后相同行列。桌面 1440×1000 为 4×3，手机 390×844 为 2×5；不同尺寸按实际墙格计算。
- 每个视觉槽一一对应，所有格共用进度与尺寸/间距变化。每个中间帧都保持直行直列、同尺寸、每行相同格数，没有菱形轮廓、洞、交叉、旋转或延迟。
- 仅首屏完整矩阵参与转场。全部 24 张专辑与独立游戏格仍保留在原生墙中，屏外内容继续随原来的一屏实际移动滚入；不添加填充内容，不改游戏格位和后续全屏展开。
- 短屏首屏包含游戏时，投影保留真实游戏格的裁切与 12% 基础遮罩。投影图片跟随真实图片的 `src/srcset/sizes/hidden` 与恢复状态，移除原生游戏图片处理标记，避免独立回退处理器相互影响。

本轮产品实现只改 `homePointMorph.ts` 与 `homePointMorph.css`。V36 首页文案、V37 Liquid Glass 搜索、选择性磁吸、后台、鉴权与站点配置保留。没有数据库迁移或业务/配置写入。
