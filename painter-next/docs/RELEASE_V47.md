# V47：手机公共导航的玻璃材质

2026-11-13 19:59:26（Asia/Shanghai）已上线，源码提交 `940cfa0`。

## 本轮改变

- 调研并实际验证开源方案，采用图片镜像与普通 SVG CSS filter 的路线，为手机顶部栏、底部导航和搜索提供图片边缘折射。没有引入整页 DOM 捕获、WebGL 或新的 npm 依赖。
- 为 WebKit 单独使用归一化坐标滤镜、长宽轴校正和解码后缓存刷新，修复“配置看似支持、实际没有位移”的问题；桌面原有滤镜不变。
- 手机底色减薄，补充明暗镜缘、当前导航项与按压反馈，修复搜索公共变量压过导航透明度的问题。维持原布局、导航目的地和搜索行为。
- 搜索用原生背景滤镜及普通 CSS 背景模糊回退，前景输入 / 结果清晰，关闭后背景恢复。
- 顶栏上滚唤出时有界跟随过渡，消除必须再次滚动或 resize 才出现玻璃图片的状态遗漏；静止无持续刷新。

具体选型、源码链接、坐标与隐私 / 性能约束见 [手机端 Liquid Glass 实现与验证](MOBILE_LIQUID_GLASS.md)。

## 真实边界

这是已有图片的网页折射增强，不能完整重建任意 DOM 或等同 iOS 原生材质。Linux WPE WebKit 的非图片原生 backdrop blur 仍可能不实际绘制；搜索有独立的已验证回退。真实 iPhone、iOS Safari 及手机 GPU / 电池表现尚未实机验收。Mac 节点已经探测，Safari 自动化设置未开启，本轮没有修改该设置。
