# V4：滚动叙事首页与文档编辑

2026-10-28。本轮按五项界面反馈迭代 `painter-next/`；Go 业务接口、PostgreSQL 表、迁移 0001–0008、公开修订合同保持原样。没有新增数据库格式，也没有引入生产 Node、Redis、云编辑服务或 SQLite。

## 实际交付

| 反馈 | 实现 |
| --- | --- |
| 文章最顶部白条 | 消除文章页外层折叠边距产生的背景带，并移除文章页导航的白色玻璃底板；保留文章、标签和搜索导航 |
| 主题面板套原生下拉框 | 直接显示自定义浅色、深色、跟随系统三个选项，带当前勾选；支持方向键、Home/End、Escape 和点击外部收起 |
| 搜索快捷键过于突出 | 顶部仅保留搜索图标，鼠标悬浮或键盘聚焦时显示提示；实际 Cmd/Ctrl+K、斜杠快捷键继续生效 |
| 首页侧重个人与视差 | 配置中的站名/简介先出现，原生滚动驱动三维物体旋转、缩放、场景切换与背景揭示；后面只展示最多两篇文章和六个标签，再进入结束场景 |
| 编辑即看到排版 | 默认文档模式，保留 Markdown 源码模式和服务端规范预览；底层仍保存 Markdown |

首页个人名称与简介读取已有站点设置。本轮没有编造职业、履历、照片或个人统计。原 Painter PNG 保持原文件；三维图形由本地 WebGL 几何生成，没有下载 Apple/GTA 的美术资产。

## 编辑器选型

| 候选 | 适配情况 | 本轮结论 |
| --- | --- | --- |
| Tiptap + ProseMirror | 官方 Vue 3 集成、可组合文档节点、Markdown 桥接；需要自行实现工具栏、菜单与兼容保护 | 采用，锁定本次安装的 3.32.0；使用开源包，不接入协作云或付费服务 |
| Milkdown | Markdown 优先，基于 ProseMirror，可实现直接排版 | 可作为替换适配器；本轮采用 Tiptap 的 Vue 与节点生态 |
| BlockNote | 块编辑交互较完整，但现有 Vue 项目需要额外适配，块模型与 Markdown 往返需另行处理 | 不在本轮引入第二套框架/块存储 |

依据均为官方资料：[Tiptap Vue 3](https://tiptap.dev/docs/editor/getting-started/install/vue3)、[Tiptap Markdown](https://tiptap.dev/docs/editor/markdown)、[Milkdown Vue](https://milkdown.dev/docs/recipes/vue)、[BlockNote Markdown 导出](https://www.blocknotejs.org/docs/features/export/markdown)。Tiptap 的 Markdown 扩展仍有 Beta 与格式限制，不能据此承诺任意 Markdown 无损转换。实际依赖许可随应用提供 `/assets/licenses/EDITOR-THIRD-PARTY.txt`。

文档模式支持标题、粗斜体/删除线、链接、列表、待办、引用、代码块、表格、图片、撤销/重做、选区格式工具和 `/` 插入菜单。图片继续通过当前站点上传、授权与引用校验。这里的体验目标是飞书/Notion 式直接编辑；没有实现多人实时协作、评论锚点或 Notion 数据库块。

## 分层与写入链路

| 层 | 文件 / 职责 |
| --- | --- |
| 文档交互 | `DocumentEditor.vue`：Tiptap 节点、格式工具、斜杠菜单、选区菜单、图片事件、输入法组合状态 |
| Markdown 保护 | `editorMarkdown.ts`：识别不支持的语法，检查解析/再序列化后的语义结构；检查过程不替换原字符串 |
| 创作流程 | `MarkdownEditor.vue`：文档/源码桥接，完整草稿快照、自动保存、IndexedDB、CAS、幂等重试、检查点、冲突和发布 |
| 业务接口 | 原 `/api/v1/posts`、`/studio/posts/:id/draft`、`/media`、`/checkpoint`、`/publish`、`/restore`；权限与 CSRF 继续在服务器执行 |
| 持久化 | 原 PostgreSQL `post_drafts`、`post_revisions`、发布指针及标签/媒体关系；正文依然是 Markdown 字符串 |
| 公开读取 | 服务器从不可变公开修订生成并净化 HTML；客户端编辑预览不能成为公开 HTML 的可信来源 |

打开现有草稿时，把原 Markdown 字符串装入两种视图，但不产生保存命令。仅修改标题、摘要、标签或封面时，原正文字符串按原样保存。只有文档正文发生真实编辑，才从文档节点序列化出新的 Markdown，然后进入既有保存队列。

保存流程为：实际编辑 → 本机完整快照 → 串行保存队列 → 固定幂等键 + `If-Match` + `expected_draft_version` → 原数据库事务 → ACK 后推进本地确认序号。旧请求响应不能覆盖继续输入的新内容。冲突继续由用户比较并明确合并；断网恢复点按账号、origin 和文章/client ID 隔离。

图片流程为：插入唯一占位 → 上传接口完成真实媒体写入 → 在当前文档内定位占位并替换媒体地址 → 随正文保存引用 → 检查点/发布时锁定有效引用 → 公开指针可见后读取。异步替换保留当前选择位置；上传未完成/失败占位阻止发布。

发布继续先等待保存和上传，创建不可变修订并原子切换公开指针。历史恢复只形成当前草稿，保留原公开版本；撤回收回公开指针与封面/正文媒体的公开可达性。完整数据库事务与时序参见 [V3 合同](EXPERIENCE_V3.md) 和 [实现架构](ARCHITECTURE.md)。

## 原文保护与限制

不能确认安全往返的正文自动转源码模式：HTML/注释、Front matter、引用式链接定义、脚注/指令/数学扩展、带附加属性的代码围栏，以及语义比对不一致的结构。原文完整保留；不把“看起来能展示”当成“可以无损编辑”。表格单元格限制为一个段落，以匹配 Markdown 表格。

选择文档模式查看不兼容内容时保持只读并提示回源码；不静默删除不支持的内容。粘贴不兼容 Markdown 时完整转入源码处理。文档模式与 CodeMirror 都保护中文组合输入；服务器仍执行内容长度、媒体、授权和 HTML 净化，不信任编辑器输出。

## 首页动效与降级

`homeStory.ts` 管理滚动进度和章节，`homeLens.ts` 负责原生 WebGL 几何，`homeStory.css` 负责全幅布局。首页模块单独延迟加载；文章、搜索和标签页不加载三维模块。没有拦截滚轮、强制滚动吸附、自动播放视频或新增动画库。

只在滚动、尺寸、主题和页面可见性变化时调度一帧，不存在空闲循环。限制渲染约100万桌面/32万手机像素与56步光线追踪，离屏/后台停止绘制。WebGL 不可用或上下文丢失时使用原 logo 静态素材；减少动效时改成正常文档流的三个章节。没有 JavaScript 时正文、文章和标签链接也正常显示。

首页借鉴官方 [Apple iPhone 页面](https://www.apple.com/iphone-18-pro/) 的视口叙事与尺度变化；也查阅了 [GTA VI 官网](https://www.rockstargames.com/VI)。本机 GTA 截图停在加载标识，不能作为已观察其完整动效的证据。参考记录见 `tests/artifacts/v4/references/`，实际成品以本项目截图和浏览器测试为准。
