`site_profile` 新增 `intro_name` 和 `intro_roles_json`，姓名最多80字、身份标签最多12个且每个1–60字。站长权限、CSRF、Origin和版本CAS继续生效；旧客户端省略新字段会保留现值。新安装默认留空，不把当前站长的个人资料注入所有部署。

## 渐变封面

自动封面改成铺满画面的渐变背景与标题排版，删除原模板的装饰条、圆形、边框等元素。保留三种样式与四组配色的存储ID，历史修订无需改写：

| 存储ID | 后台名称 | 表现 |
| --- | --- | --- |
| editorial | 深邃渐变 | 深色背景、左侧标题 |
| geometric | 流彩渐变 | 流动色彩、左下标题 |
| minimal | 柔光渐变 | 浅色背景、居中标题 |

墨蓝、苔绿、陶土、梅紫配色仍可选；上传和无封面继续可用。服务端生成 SVG，不新增图片生成服务或运行依赖。XML转义、混合中英文换行、200字标题和四行布局保护继续生效。

SVG 的 `gradient-v1` 标记参与内容ETag。公开封面继续 `max-age=0, must-revalidate`，每次复用缓存前核验公开指针；更新渲染后可正确刷新，撤回后不能借旧ETag读到封面。HEAD返回GET对应的类型、长度与ETag，正文为空。

## 三个时间与开关

每篇文章的“文章信息与展示”新增三个独立勾选项，默认全部显示：创建时间、最后编辑时间、发布时间。保存/发布后在文章作者信息下展示，使用北京时间，机器可读的 `datetime` 保留 UTC ISO 格式。

| 字段 | 数据来源与含义 |
| --- | --- |
| created_at | `posts.created_at_ms`：文章记录创建时间；数据库触发器阻止后续修改 |
| updated_at（公开） | 当前公开修订的 `content_updated_at_ms`：该内容最后保存为草稿的时间，在创建修订时锁定；不查询正在编辑的草稿 |
| published_at | 当前 `post_publications.published_at_ms`：当前版本的发布时间；重新发布会更新 |
| last_edited_at（后台） | `post_drafts.updated_at_ms`：当前私有草稿最后保存时间 |

`post_drafts.date_display` 与 `post_revisions.date_display` 保存三个布尔值：`created`、`updated`、`published`。开关属于完整草稿快照，进入自动保存、IndexedDB恢复、CAS/幂等、内容hash、检查点、恢复与发布。旧API客户端省略字段时保留已保存选择；显式三个false表示全部关闭。

发布事务从已锁定草稿读取编辑时间与开关，连同正文写入不可变修订，再切换公开指针。仅保存草稿或创建检查点不会改变公开时间或展示选项；恢复历史版本带回其开关，但需再次发布才影响读者。JSON-LD 日期字段也遵守展示开关；RSS和检索仍使用真实发布时间完成其数据职责，开关不改变文章排序或访问权限。

迁移仅对来源草稿版本与当前保存版本完全一致的历史修订回填可确认的编辑时间，旧导入记录还需确认该时间不晚于公开时间。其他历史修订显示“未记录”，不拿发布时间或较新私有草稿时间伪造最后编辑时间。旧导入格式没有独立的公开编辑时间：新导入修订保留未知，私有草稿仍保留其输入的更新时间；用户后续保存、发布即开始记录准确快照时间。

数据库约束验证日期选项完整且为布尔值，修订插入触发器核对时间与已保存草稿一致，旧导入可保留空值。修订及创建时间不可通过后续SQL更新；内部导入标记不能从HTTP输入。

## 升级与验证

升级前创建真实数据库/媒体备份并保存旧程序与私有配置。候选库由该备份隔离恢复，执行0009并完成真实业务验收；最终在原库执行同一迁移与程序更新，不将候选QA库覆盖回原库。迁移提交后失败应向前修复或从完整备份隔离恢复，不盲目降级schema。

后端日期/导入/配置与现有业务使用真实PG、race检查；浏览器验证介绍配置、封面、三项独立显示、公开隔离、JSON-LD、恢复与撤回，并扩展原离线/丢响应回归包含日期选项。全部结果与桌面/手机深浅色截图见 `tests/artifacts/v5/` 和 [验收记录](VALIDATION.md)。
