# V18：中性界面与层叠书页首页

这轮按用户指定的 shadcn 风格重做管理界面，并让公开页面沿用同一套更简单的视觉规则。参考官方 [dashboard-01](https://ui.shadcn.com/view/new-york-v4/dashboard-01)、[sidebar-07](https://ui.shadcn.com/view/new-york-v4/sidebar-07) 和 [主题变量说明](https://ui.shadcn.com/docs/theming)。实际控件继续使用项目现有的 Vue 实现，没有引入 React、Radix 或新的运行服务。

## 界面变化

- 后台使用中性侧栏、内嵌的实色工作区、面包屑分隔、细边框表格与表单。文章、标签、片语、友链、站点设置、个人空间和编辑器共用这套规则。
- 公开页面改为白色／zinc 深色表面、黑白主按钮、sans 标题和更安静的导航。搜索、作者页、文章、讨论和登录页保持功能与信息层级。
- 原 Painter 图标保留；已保存的文章封面和作者背景仍是实际内容，不修改成主题配色。
- 延续 V17 尺寸：普通控件桌面36px、小屏或粗指针44px；内部选中项28/36px。圆角继续为4px选项、6px控件、8px菜单、12px面板，公开导航24/20px。

颜色与字体集中在 `web/frontend/src/shadcn-theme.css`；工作台布局在 `studio-shadcn.css`。`style.css` 保留共享尺寸规则，旧蓝色主题变量不再作为第二套定义。

## 首页与资源

移除旧 WebGL 环形模型及 `homeLens.ts`，改为三层原生 DOM 书页。封面取实际配置的姓名与介绍，滚动时轻微倾斜、展开；个人介绍的三个章节仍随原生滚动切换。文章封面横向浏览章节继续保留。

页面没有持续空转的绘制循环，也不下载模型。仅在滚动、尺寸、动态偏好或页面可见性变化时请求绘制；后台标签页停止排队。减少动态效果和无 JavaScript 环境使用正常文档流，个人介绍和文章入口仍可阅读和操作。

Geist Latin 字体以29400字节的本地 WOFF2 发布，中文使用本机 sans 字体，无运行时 Google Fonts 请求。SIL OFL1.1许可证位于 `/assets/licenses/Geist-OFL.txt`，来源见 `web/frontend/src/assets/Geist-SOURCE.md`。

## 功能与数据边界

接口、权限、数据库表和 schema14保持不变。编辑器的同一份文章信息、文档／源码切换、CAS、恢复和发布事务继续沿用原实现。选择菜单的自然高度测量包含新的边框，避免菜单底部多出少量裁切。

验收内容来自隔离候选库中的明确标注测试文章，候选数据库和媒体不会带入正式实例。正式升级只更换嵌入新资源的 Go 程序，继续使用原数据库、媒体目录与私有环境文件。

构建、只读浏览器验收、实际截图复核和正式资源指纹记录位于 `tests/artifacts/v18/`。浏览器脚本拦截内容与配置写入，埋点请求使用测试响应；SSR集成测试各自使用临时数据库。本轮380项路由与交互检查、24张截图的64项检查、320×667首页的5个情形及4项SSR测试通过。独立复核只指出手机分析页日期控件叠压，修正后在320/390/720px通过几何检查，并替换同名截图做针对性复核；其余23张原图所涉样式没有改动。验证记录应按实际报告范围解读，未改动的后端测试不计作本轮重跑。
