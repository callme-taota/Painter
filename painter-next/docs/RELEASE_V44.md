# V44：按设备组织交互的 Painter

2026-11-13 已部署。完整约定见 [全端体验与交互规范](CROSS_PLATFORM_EXPERIENCE.md)，界面规则见 [手机表面记录](../web/.impeccable/surfaces/mobile-experience-v44.md)。

原来手机把桌面的侧边工具、弹出搜索、长设置页和编辑动作一起缩进窄屏。本轮保留原有视觉原则、URL、权限和数据契约，将手机改成独立的任务组织。当前仍是手机 Web，没有另建原生 App 或 `/m` 内容副本。

## 已实现

| 场景 | 手机 | 平板与桌面 |
| --- | --- | --- |
| 公共导航 | 底部首页 / 文章 / 动态 / 更多，工具进底部面板；不占阅读右边距 | 保留右侧独立玻璃工具及既有顶部栏 |
| 搜索 | 全屏液态玻璃任务，取消、建议及完整结果入口；中文输入与软键盘空间处理 | 保留 Raycast 风格浮动搜索 |
| 搜索筛选 | 标签 / 排序底部面板；暂存、取消、重置和查看结果；原有同一组 GET 表单字段 | 保留就地筛选面板 |
| 首页与收藏 | 自然纵向章节，项目 / 唱片 / 游戏 / 最近文章原生横滑，日历有可点按的日期操作 | 保留原视差、连续变换与配置顺序 |
| 阅读与作者 | 对称留白、17px 正文、作者不遮封面；目录进入更多；卡片 / 评论 / 推荐分层 | 保留宽屏阅读列与作者栏 |
| 工作台 | 任务标题、底部内容 / 新建 / 我的 / 全部；完整功能底部面板 | 平板保留抽屉，桌面保留分组侧栏 |
| 资料与账号 | 资料 / 主页 / 安全；登录设置再分访问控制 / GitHub / 应用接入 | 保留宽屏表单与应用表 |
| 创作 | 正文 / 文章信息两步骤，共享原稿；下一步再发布，保存与更多在底部 | 保留完整编辑工作区，信息栏按可用宽度展开 |
| 内容管理 | 文章与标签按记录显示，主要编辑操作直接可点 | 保留比较效率更高的表格 |

手机规则以可用宽度 720px 为主要切换点；工作台 960px 抽屉和编辑器 1360px 信息栏断点继续按内容适配。所有触屏关键操作以 44px 为目标，适配 safe-area；键盘出现时收起无关固定操作。宽度变化不丢弃同一份表单或编辑稿。

手机临时任务使用原生 dialog 与共享历史管理：Back 先关闭，Forward 可以恢复；链接、目录与表单提交先完成临时层退出再导航。已修正筛选框回车留下空历史、手机搜索跨到桌面后提交被返回吞掉、目录 hash 丢失等边界。

## 验证

- 前端 Vue / TypeScript 检查及发布构建通过；87 个应用模块继续混淆，4 项混淆构建测试通过，没有开放 source map。
- PostgreSQL 18 隔离集群上的公开 SSR / 首页 / 作者 / 搜索 / 文章相关 Go race 测试通过，未用正式数据库执行集成测试。
- 最终候选 **195 项浏览器检查通过**：公开壳 32、历史 19、公开内容 102、工作台 42；54 张路径截图，独立审阅 33 张代表图，结论 `ship`。
- 检查覆盖 320 / 390 / 430 手机、710 与 844 低高度横屏、820 平板、1440 桌面和明暗主题；收藏横滑及纵向跨轨滚动使用 Chrome 合成触摸验证。
- 公网另有 7 项只读手机冒烟检查通过：固定底栏、侧栏退场、更多单一账号入口、Back 关闭及全屏搜索；无页面 JS 错误、无正式业务写入。
- 浏览器模拟、合成触摸与模拟键盘几何不代表真实 iPhone Safari、Android 软键盘或系统边缘返回已验收。VoiceOver / TalkBack、物理设备性能及弱网仍需实机验证；不扩大已验证结论。

原始记录位于被 Git 忽略的 `tests/artifacts/v44/`，可复用脚本位于 `tests/browser/v44-mobile-*.cjs`。截图和 fixtures 使用隔离测试内容；正式环境没有插入这些演示文章、动态、评论或封面。
