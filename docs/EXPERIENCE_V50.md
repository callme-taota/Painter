# V50：连续列表、站内搜索与编辑保护

## 用户裁决

落实 2026-11-14 产品走查的 1、2、3、7、8、10。第 4 项按用户新要求覆盖全部可分页列表：预加载、自动续载，不提供手动翻页或“加载更多”。保留纯 icon 导航；第 5 项内网分享复制、第 9 项登录恢复提示不修改。

## 实现

- 网站信息、功能设置和个人资料保存各自基线，显示未保存状态，通过浏览器离开确认保护内容。分区切换保留表单；成功保存更新对应基线。没有把密码、联系方式或表单草稿加入浏览器持久化存储。
- 空文章页的主按钮返回首页。首页按真实公开文章状态省略空阅读区；默认文章跳转在没有文章时改为关于页，指向空文章的收尾区不再展示。存在文章时保留站长配置的展示顺序与内容。
- 公开文章、专栏、动态、片语、作者文章、游戏和搜索结果保留首批 SSR，接近末尾约 1000px 时自动请求并追加。后台文章、动态、专栏、片语、展示墙、个人列表、成员与评论，以及文章讨论、专栏文章选择器和内容卡片选择器采用同一自动续载机制。批量读取不改成一次性全库请求；片语公开页和管理页首批改为 20 条。已经全量返回的固定选项、图片查看和章节相邻阅读没有引入分页操作。
- 请求在途期间不重复拉取同一批；筛选重置、迟到响应隔离、追加去重，失败保留已显示内容，人工重试仅用于失败恢复。末尾停止读取。搜索游标因内容变更失效时给出重新载入列表入口。新追加的动态图片、片语复制、内容卡片和游戏图片回退继续初始化。
- 游戏名称搜索使用参数化、NFKC／case-fold 的字面子串匹配，与平台筛选、排序和已签名游标绑定，显示真实筛选数量。平台与排序链接保留查询。
- 站内完整搜索增加全部／文章／专栏／动态／片语。只读取当前公开数据；撤回、删除与私人草稿不进入结果和搜索建议。标签／作者条件沿用原文章搜索，显式文章模式保留原展示和排名。原 `/api/v1/search` 不带 `type` 时保留文章 API 兼容合同，`type=all` 开启跨内容搜索；界面默认搜索全部内容。保留既有搜索并发、超时与结果数量边界。
- 编辑器继续使用原保存、恢复、CAS 与发布协议。显示自动保存或草稿已保存，把“留检查点／不可变修订”改成“保存历史版本／历史版本”，说明版本可恢复且不会自动发布。

没有新增数据库迁移、服务或依赖。公开页无 JavaScript 时保留首批可读内容，后续自动续载需要 JavaScript，界面不再提供手动分页。
