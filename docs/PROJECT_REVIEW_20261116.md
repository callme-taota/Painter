# Painter 当前缺口与下一步

2026-11-16，基于 `next` 当前源码与公开页面检查。已实现的能力不重复列为待办；以下是建议顺序，不表示本轮已经实施。

## 优先顺序

| 优先级 | 缺口 | 当前边界 | 建议的一期闭环 |
| --- | --- | --- | --- |
| P1 | 完整的个人主页归属 | `/users/{id}` 已有本人文章、动态、专栏与背景；原视差、游戏、音乐、图片、项目配置仍是站长单例，原首页文章和热力图仍统计全站 | 先完成每人的介绍、布局、本人文章与热力图；收藏墙、凭据、同步任务与媒体授权一起按用户迁移。见[多作者主页](MULTI_AUTHOR_HOMES.md) |
| P1 | 仓库内统一的交付检查 | 已有 Go 测试、前端类型检查与构建、多个浏览器脚本；目前仓库没有随代码交付的 CI 配置 | 固定 PostgreSQL 18 隔离测试，串起 Go 检查、前端构建与关键页面 Playwright 检查；首页转场、手机自然滚动和无内容状态纳入回归 |
| P1 | 关注后的内容流 | 关注关系和名单可用，站内目前只有全站最新，没有关注内容流 | 站内提供「全部 / 关注」，先支持文章；服务端限定当前读者，游标绑定读者及筛选，不由前端拼接多个作者的结果 |
| P2 | 持久通知 | Toast 已统一，但没有通知收件箱、已读状态或评论通知投递；保存了 SMTP 配置不等于已经发送通知邮件 | 先做评论 / 回复等站内通知、未读计数和幂等投递，再做私信与可选邮件通知 |
| P2 | 作者可携带的数据导出 | 已有单篇 Markdown 导出、文章 JSON 导入、整站备份；缺少作者自己的完整迁移包 | 按本人范围导出公开文章、媒体、标签和专栏关系，包含版本化 manifest 与校验和；草稿和历史另设选项，不给作者整站备份 |
| P2 | 异机备份和主动告警 | 已有本地自动备份、保留策略、隔离恢复验证、状态与健康检查；仓库工具没有异机副本送达与失败告警的闭环 | 配置一个加密异机副本目标，记录送达时间；备份超期、任务失败和服务不可达时告警。这里不据此判断生产机外是否有人工作业或人工副本 |

## 不需要重复建设

- 本地账号、GitHub 登录、TOTP、恢复码、会话管理、注册与外部登录开关都已有实现。
- 草稿、自动保存、历史版本、冲突处理、公开快照、撤回与审计已存在，适合可信朋友共同写作。
- 搜索、连载专栏、三层分享、受控正文卡片、作者页、产品目录、中英文和 Chrome 独立窗口能力都已落地。
- RSS 有真实实现：后台关闭时 `/rss.xml` 返回 404，开启后提供最近 20 篇公开文章摘要。按作者 / 专栏订阅尚未提供；用户此前要求默认关闭，本轮不改开关。
- 监控入口和本地备份状态已存在；缺的是把异常主动送到维护者，而不是再做一套状态页面。
