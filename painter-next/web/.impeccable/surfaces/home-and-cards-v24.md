## First viewport and hierarchy
The library pairs a compact shared heading/sort row with a three-column collection of large Steam library portrait covers; two columns on intermediate widths and a single legible cover on narrow phones. Each image carries the card, titles use equal two-line measures and hours share a bottom baseline. The home frequency section is a quiet, horizontally scrollable calendar with exact day counts, a shared green intensity scale and honest source/timezone/date range. The repository section is a neutral overlap of tall playing cards, with real name/description/language/stars rather than invented statistics.

## Signature interaction
Hover/focus lifts a project card and shifts its neighbors aside to expose its content. Keyboard and touch reveal the same item; native external links remain primary destinations. Reduced motion keeps a readable collection, no idle loop. A single shared lightbox opens uploaded article images. Inline preview appears on hover or focus, supports explicit touch inspection and dismissal, never fetches third-party metadata on reader request.

## Data and configuration
Activity uses currently-public articles/moments, counted once at first publication in a configured IANA timezone. Editing does not increment, withdrawal/deletion removes that item; do not label it GitHub contributions or historical edit activity. Owner selects source/year, visibility/order and titles; projects have their own visible/order/manual overrides, bounded provider refresh and failure-preserved local snapshots. Unknown stats are absent, not zero. Missing repository selection remains honestly empty until configured.

Unknown types/versions degrade to ordinary code/link; known invalid data produces an explicit validation error. No arbitrary HTML/iframes, no A2UI runtime dependency. Preserve media ownership/revision links and old published versions. Verify document/source roundtrips, source editing, hover/focus/touch, mobile overflow, errors, zero/unknown states, real dates, provider SSRF bounds, both themes, noJS/reduced motion, and existing routes. One coordinated matrix, bounded finish review, additive schema backup/promotion and separate intentional settings activation.
