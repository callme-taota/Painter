# 关注更新流

`/following` 汇集当前账号所关注作者的公开文章和动态。桌面从「浏览内容」进入，手机从「更多」进入；个人中心与个人空间导航也提供入口。「管理关注」仍使用 `/me/following`，不与阅读更新混在一起。

## 展示与时间

- 默认混排，也可切换「文章」「动态」。条目显示当前作者资料、首次发布时间、文章标题和摘要或动态文字、公开封面与真实详情链接。纯图片动态保留图片入口。
- 首次关注后可阅读该作者已经公开的历史内容。按首次发布时间倒序排列；同一时间按资源类型和数字 ID 稳定排序。后续发布编辑或重新发布旧内容会更新公开快照，但沿用首次发布时间，不置顶；保存草稿不会改变公开内容。
- 专栏章节作为文章出现，不重复产生专栏事件。片语目前是站点级内容，没有作者归属，不纳入关注流。
- 首屏由服务器渲染。启用 JavaScript 后复用首屏数据，接近末尾时预加载后续内容；筛选和手动刷新重置游标。刷新失败保留原内容并明确提示，分页失败保留已读条目并提供重试。末尾停止请求。

界面沿用现有中性色、字体、控件和 Apple 蓝链接约定；不新增固定工具按钮。手机采用单列阅读、紧凑筛选和足够的触控区域，界面语言支持简体中文与 English。无 JavaScript 时首屏和原生筛选、详情、作者链接仍然可用。

## 数据链路

`当前会话 → Require → 当前关注关系与有效作者 → public_posts / public_moments → 同一排序与分页 → 当前公开封面 → 有界 DTO → SSR / Vue 阅读列表`

读取时聚合，不新增分发任务、消息队列、物化收件箱、数据表或定时轮询。一次 SQL 同时读取有效关注数、有限条目及这些条目的公开首图，避免按作者或条目逐个请求。文章读取不可变修订的当前发布投影，动态读取当前公开文本及 public 图片集合；草稿文字和草稿图片不参与查询。

`GET /api/v1/me/feed?type=all|post|moment&limit=20&cursor=...` 返回：

```json
{
  "viewer_id": "7",
  "type": "all",
  "available_types": ["post", "moment"],
  "following_count": 1,
  "items": [{
    "id": "post:12",
    "content_id": "12",
    "type": "post",
    "url": "/posts/12",
    "title": "示例文章",
    "summary": "公开摘要",
    "published_at": "2026-11-21T01:00:00Z",
    "author": {"id": "2", "display_name": "示例作者", "avatar_url": ""},
    "cover_url": "",
    "image_count": 0
  }],
  "next_cursor": "",
  "has_more": false
}
```

示例为格式说明，不是站点统计。摘要最多 240 个 Unicode 码点；每页默认 20 条，最多 50 条。文章和动态的数字 ID 可以相同，前端用 `post:12` / `moment:12` 作为不同条目的键。签名游标绑定当前账号、筛选和页大小，并携带完整排序键；伪造、跨账号和跨筛选的游标被拒绝。

连续加载不是历史快照：每页都重新检查当前关注和公开状态。撤回、删除、取消关注或停用作者后，后续读取立即排除对应内容；更晚发布的更新不会插入已有游标之前，刷新后才从顶部看到。已经显示的条目在刷新或重新进入时重新读取，不建立浏览器持久化副本。

## 权限与缓存

SSR 与 API 都要求有效登录，复用访问开关、停用、MFA 和会话撤销规则。页面未登录时安全跳转到登录页并保留站内返回地址；API 返回 401。成功、错误和跳转均使用 `private, no-store`；页面声明 `noindex,nofollow`，不加入 sitemap，robots 排除该路径。公开条目本身不等于公开某人的关注关系。

前端核对每次响应的 `viewer_id`，使用请求取消与版本号隔离迟到结果。退出、过期或检测到账号变化时清空并隐藏条目；进入浏览器返回缓存前隐藏列表，恢复及标签页返回时重新验证账号，再重新读取。验证期间只显示安全的标题和状态，不展示旧条目。不在 localStorage、IndexedDB 或服务工作线程中保存关注流数据。

## 验证与部署

PostgreSQL 18 测试覆盖同时间、跨类型相同 ID、游标隔离、混排与筛选、首次发布排序、公开快照、图片与作者状态、关系变化及权限。SSR 测试验证原生阅读、JSON 转义、登录返回、私人缓存和搜索引擎隔离；源码浏览器测试验证分页、迟到请求、刷新失败、账号切换、缓存返回和小屏交互。完整 Linux 构建另在隔离数据库中验证真实接口与界面。

本次无数据库迁移。切换二进制前仍需新备份与真实隔离恢复验证；保留现有账号、内容、域名、监听、Tunnel 和访问设置。
