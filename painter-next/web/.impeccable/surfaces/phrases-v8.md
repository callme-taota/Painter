# V8 片语

Mode: Experience. 站长添加句子或词语，选择公开后在独立页面展示。内容/来源为真实保存值，草稿不可见；不预置作品或伪造个人署名。

## Direction contract

THESIS: 用一段可停留的大字阅读表达短句，滚动翻过下一条；沿用个人站的原生滚动关系。

OWN-WORLD: 既有纸面、墨色、Newsreader/中文衬线字体和克制蓝色。大字占据页面中心，控制收于边缘，来源安静地跟随文字。无新字体、插画或装饰卡片。

STORY: 首页找到片语入口 → 阅读一条 → 原生滚动或上一条/下一条 → 复制需要的文字。站长从后台维护和撤回，前台不接收投稿。

FIRST VIEWPORT: 标题与真实条数在页首；首条句子占主要视野，短词更大、长句自然延伸，不截断。下缘导航提示下一条，页脚保持原最小配置。空库如实呈现空状态。

FORM: code-led existing-world extension，一屏一句的初始实现。向用户提供过三种结构的可选问题，在独立后台工作后仍未收到选择，按已声明的第一种继续；用户可后续调整。未运行新世界抽签，无生成图片或参考图授权。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
