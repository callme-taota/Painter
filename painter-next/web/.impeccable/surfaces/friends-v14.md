# V14 友链名录与管理

Mode: Read for the public directory; Operate for owner management. Extend the existing Painter publication and studio rather than replacing their visual world.

THESIS: A quiet, readable directory gives each saved website its own identity, with a clear management flow for the owner.

OWN-WORLD: Existing paper/ink/blue tokens, serif publication headings, sans interface text, original Painter identity. No invented real friends, new artwork, gradients or decorative glass.

STORY: Public title and editable introduction → open two-column site list → quiet ending. Each site has an optional avatar, name, host and description, with native new-tab navigation. Narrow screens become one column; fallback initials keep missing images useful.

FIRST VIEWPORT: Configured title and introduction establish purpose before the first few sites. A true empty state remains intentional. The public header/footer stay minimal; entry points join the homepage ending and About page.

FORM: Owner-only Content → Friends has two tabs: saved links and page settings. The list is separate from a supporting editor; on narrow screens the editor precedes the list. Add/edit/show/hide/order/delete, clear save feedback, failed reads, unsaved changes, confirmation and CAS conflicts preserve user work. Page title/intro/enable switch are separately saved; closing hides the page and entries, retaining data.

FINISH: Real PG validation, permission/CSRF/URL/CAS/idempotency checks, SSR/no-JS and sitemap switch; real candidate CRUD and restoration; keyboard/touch, custom state picker, bad/missing avatar, long content, desktop/mobile light/dark captures and independent review. Back up formal data, migrate once and retain original media/configuration. No default real links or public submission form.
