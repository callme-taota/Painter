## 交付内容

**连载专栏**：后台“内容管理 → 专栏管理”创建、编辑、上传封面、添加已有文章、上下编排、公开 / 草稿、连载 / 完结和删除。手机进入单个专栏后聚焦编排，提供返回列表。公开 `/series` 及详情由 SSR 输出目录、搜索、状态筛选与游标分页；文章末尾可连续阅读上一篇 / 下一篇。当前最多 300 章，删除专栏保留文章，撤回文章立即从公开目录和相邻导航消失。草稿可以先编排但不会泄漏私人标题。

**三层分享**：文章、动态、片语、专栏都有短链接、可复制 iframe HTML、独立摘要引导页。只分享当前公开资源，关闭再打开会重新校验；撤回后旧分享入口 404。嵌入卡片不加载业务脚本或会话，只使用独立 CSS。外站仍可自行禁止 iframe。详情见 [数据与接口文档](SERIALS_AND_SHARING.md)。

**个人中心**：普通读者默认是收藏、关注、阅读足迹，另有资料、公开主页、安全任务。创作者额外获得写作入口。公开 reader 主页展示公开身份 / 简介 / 背景和关系信息，不展示假空文章列表或作者搜索。收藏、足迹、邮箱、电话不进入公开页面。停用用户的个人页与公开用户 DTO 都返回 404。

**失败与会话交互**：资料 400 / 409 保留表单；确认重读只更新资料，不卸载背景和安全组件。安全区 / 应用接入切换保留一次性信息。修复会话协调带来的编辑器退出竞态：主动退出等待在途本地恢复点写完后清理；会话过期先保留原账号最新恢复点，再跳带原路径、query 和 hash 的登录页。

## 请求审计的实际结果

| 场景 | 录制结果与处理 |
| --- | --- |
| reader `/me` 首屏，320 / 390 / 1440px | 业务 GET 仅 `/session` 与 `/me`，共 2 次 |
| 主页外观 / 安全 | 首次打开各增加一次，返回不重取；409 确认重读只增加 `/me` |
| 登录 reader 阅读文章并进入讨论 | 相关业务 GET 共 5 次：session、metrics、post-states、site、comments 各一次；正文不再从客户端请求 |
| 公开个人页关注 | 一次 follow-state 替代遍历全部 following 分页 |
| 分享面板 | 首次打开一次，切换三种方式不追加；重新打开重新校验 |
| 独立分享 / 跨源嵌入 | 1 CSS、0 JS、0 session 请求 |

这些计数来自隔离候选的真实接口，不含图片 / 封面、埋点与主动互动；正文卡片、登录状态和滚动位置会改变请求数量。通用 GET 只合并同路径的默认在途读取，不合并写操作或带 AbortSignal 的请求；会话 / 私人关系的成功结果只在当前文档内存有短时有效期。服务端每次写入仍重新鉴权。

仍应继续优化：编辑器默认文档模式 / 隐藏预览时的多余渲染、表单离开保护的一致性、大列表单行忙碌态与失败重试。文章选择器可进一步增加轻量投影；本轮没有宣称完成全站慢 SQL / 真实大流量审计。详见 [审计与后续交互优先级](REQUEST_AND_PROFILE_AUDIT_V49.md)。
