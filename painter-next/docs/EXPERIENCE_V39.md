# V39：站内引用与界面细节

2026-11-08。保留 V38 规则矩阵、Liquid Glass 导航与搜索，补文章引用卡并收敛公共界面。

## 使用与展示

- 文章编辑器的「卡片」可选择「站内动态」「站内片语」，筛选已加载的公开列表、加载更多、预览、插入与重新编辑。文档模式另提供两种斜杠命令，Markdown 模式沿用同一协议。
- 动态卡展示实际作者、日期、完整文字、最多三张公开图片及真实图片总数；片语卡展示句子/词语与已存来源。卡片跳转原内容，片语新增稳定的 `/phrases/{id}` 页面。
- 清理搜索、动态、片语与游戏空态的界面标题末尾句号；不修改文章、姓名、游戏、专辑或用户正文。
- 首页关闭滚动暖色背景，使用原本主题的素色。通过既有管理员 API 仅将 `warmth_enabled` 设为 false，配置版本 10 → 11，保留其他首页与 Steam 设置。原开关仍可配置，视差与影像场景保持原行为。
- 个人作者主页去掉外围大卡片，收紧保留的自定义封面与身份区域，头像/姓名/关注同排、简介在下，同页搜索与文章列表对齐。手机封面完整展示，长昵称与简介可正常换行。
- 正文中的普通链接、明确的阅读动作和导航选中状态保留蓝色；页脚、作者元信息、常规导航、次要入口恢复中性色与悬浮下划线。文章引用卡保持中性内容层级。

## 游戏墙修复

实际复现两处自选封面问题：公开游戏映射无条件用 Steam 官方竖图覆盖上传封面；移除已保存上传时丢失远程图地址，导致预览为空和保存验证失败。

现在有已选上传时保留该公开封面；移除后恢复同游戏的官方图或原远程图。PlayStation 不冒用 Steam 图片，没有合法图片时给出明确表单错误。仅解除引用，不删除原媒体文件。「公开展示」明确同时影响首页与完整游戏墙，首页依然最多五项。平台筛选和排序未复现故障，保持现有行为。

## 引用的数据边界

站内卡继续使用版本 1 的 `painter-card` 代码块，只保存引用身份，例如：

```json
{"v":1,"type":"moment","url":"/moments/41","ref_id":"41"}
```

片语对应 `type: "phrase"` 和 `/phrases/{id}`。不允许附带正文、标题或图片快照。原 GitHub、Steam、Apple Music、网页卡及行内链接协议兼容。

公开文章、预览、历史修订与 About 在读取时，用一个有界 SQL 从当前公开动态/片语投影展开，并转义正文；不覆盖不可变修订 HTML。来源撤回或删除后，下次读取显示不可用，不残留旧正文或图片。动态文字不复制进文章搜索索引，动态媒体不变成文章媒体引用，避免撤回后被文章继续保持公开。

新公开读取接口为 `GET /api/v1/content-cards/{kind}/{id}`，仅支持当前公开来源；原编辑器解析接口负责作者权限与校验。接口和 SSR 沿用 `private, no-store`。预览复用写事务连接展开卡片，避免并发预览各占连接后又等待第二个连接。

## 验证与隔离

- TypeScript/Vite、Linux Go 生产构建和差异检查通过；界面检测器无发现。
- 独立 PostgreSQL 18 测试集群中全包 `go test -race ./...` 通过。修复事务连接复用后，相关新旧卡片 15 项 race 再验通过，包含真实 HTTP 单连接池、两秒 deadline 下的预览展开。
- 公开 → 来源更新/撤回 → 文章、预览、历史修订与片语独立页的边界均验证；注入、非法引用、版本兼容、无外部网络请求与媒体可见性覆盖。
- 旧/新 TS 协议各七项、浏览器运行时 19 项、真实 Vue 插入与再编辑九项通过。这些卡片浏览器内容为明确标记的合成隔离 fixture，实际 API/数据库边界另由 PostgreSQL 集成测试验证。
- 游戏墙十二项浏览器内存检查与真实隔离数据库 CAS、幂等、权限、CSRF、媒体解除引用回归通过。作者页 56 项检查、九张截图逐张查看，包含真实空数据与临时长内容布局。
- 更新一个过时的首页测试：原断言依赖 V36 已移除的可见说明，现改验证隐藏的日期实时播报语义，未修改活动统计实现。

正式库只修改用户要求的背景开关，没有添加测试文章、动态、片语、账号或媒体。正式数据维持干净。独立测试实例使用 `/tmp/painter-v39-card-pg`，正式服务与数据库保持原配置。

本地证据在 `tests/artifacts/v39/`，卡片合成 UI 的截图和报告已归档到其中的 `cards/`。实际浏览器验证使用 Chromium，不代表实体手机或 Safari 测试。
