# Painter 产品体验走查 · 2026-11-14

## 目标与范围

回答本地默认分支，并实际体验当前产品，提出 10 个明显影响使用的问题。本轮交付走查记录，不修改产品实现。

- 本地保存的远端默认分支：`refs/remotes/origin/HEAD → refs/remotes/origin/next`。
- 当前工作目录分支：`unstable`，走查前 HEAD 为 `ff2ec40`。另一工作目录 `Painter-next` 检出 `next`。这里陈述本地记录，未刷新远端引用。
- 正式公开站：内网现有服务；登录页按现有配置跳转到公网规范地址。桌面 1440px、手机 390px 的 Chromium 独立浏览器上下文。
- 后台、写作与带内容的阅读：使用正式运行程序，另起仅监听本机的临时应用，连接独立 PostgreSQL 18 测试库 `painter_ux_review`；使用程序自带示例文章和新建临时站长。正式站当前没有公开文章，旧站长会话失效，不能把隔离站体验描述成正式账号体验。
- 公开站 API 非 GET/HEAD 请求被拦截；未发布正式测试内容、修改正式配置或恢复正式账号。隔离站实际体验登录、写作、自动保存、手动保存、检查点、个人资料和专栏编排。
- 单人产品走查，参考 Impeccable 的启发式原则；没有进行双人独立设计评分。浏览器连接工具没有可用浏览器，使用项目既有 Playwright 与本机 Chrome。

## 10 个问题

### 1. 网站信息与个人资料离开页面时静默丢失（P1，已复现）

**复现**：隔离站 `/studio/settings#site` 修改“站点名称”，不保存，点“首页内容”，再回“网站信息”；输入回到原值。`/me#profile` 修改“公开昵称”，进入收藏页再返回，同样丢失。两条路径均未出现离开确认。

**影响**：站长整理长篇关于页、用户编辑个人简介时，误点导航就可能重写。网站设置内仅切换 hash 分区会保留表单，离开整个页面却丢失，保护边界也不直观。

**建议**：统一未保存状态与离开保护；对长文本提供本地恢复。可参考已有标签、专栏、主页背景表单的保护。

**定位**：`web/frontend/src/App.vue` 中网站信息与个人资料表单、导航离开处理。

### 2. 空文章列表的主按钮回到自身（P1，已复现）

**复现**：正式 `/posts` 显示“文字正在酝酿中”，点“浏览文章”，仍停留 `/posts` 的同一空态。

**影响**：按钮没有推进用户任务；反复点击也找不到可读内容。

**建议**：移除自循环按钮，给出确实有内容的去处，例如片语、游戏墙或首页。需要判断目标是否也为空。

**定位**：`web/templates/page.html` 的 `post-list` 空态。

### 3. 首页“读一些文字”把用户送到空阅读区（P2，已复现，依赖当前内容状态）

**复现**：正式首页首屏点击“读一些文字”，跳到 `/#home-writing`，落点显示“文字正在酝酿中”。1440×844 视口下，首页总高 13,819px，落点滚动位置约 12,975px；1440×960 下总高 15,629px。用户也可以用首屏锚点或侧边文章入口跳过滚动，并非必须逐屏滚完。

**影响**：主要阅读承诺与落点不一致。自然向下浏览时，介绍、项目、音乐、游戏占据较长路径，阅读区却没有内容承接。

**建议**：按公开内容状态决定是否展示阅读号召和对应场景；有文章时提供最近标题入口，无文章时让主按钮通往确实可读的内容。

**定位**：`web/templates/home.html`、`web/frontend/src/homeStory.*` 及首页区块配置。

### 4. 游戏列表翻页后没有“上一页”（P2，已复现）

**复现**：正式 `/games` 共有 112 条游戏，第一页 20 条。点“下一页”进入第二页，页底仍仅有“下一页”，没有上一页或当前位置提示。

**影响**：找回刚才看到的游戏需要依赖浏览器后退；直接打开带游标的链接时，页面自身无法返回上一批。

**建议**：增加返回上一批的可用路径及“当前展示第几批／多少项”提示，保持已有排序和平台筛选。

**定位**：`web/templates/page.html` 的共享 `.pagination`；本轮实际验证游戏列表，不推断其他列表均已复现。

### 5. 内网分享面板的“复制短链接”无法自动复制（P2，已复现，限定 HTTP 内网）

**复现**：内网 HTTP `/phrases` → 分享片语 → 复制短链接，提示“未能自动复制，已选中内容，请长按或使用复制快捷键。”测试上下文 `isSecureContext=false`。

**影响**：内网是项目支持的访问方式，按钮的预期却变成额外手动操作。同站片语“复制文字”已有另一套非安全上下文降级实现，行为不一致。

**建议**：统一复制组件与降级体验；能自动复制时直接完成，否则让手动复制的入口、选区和说明更直接。这里没有将浏览器的安全限制归因为接口故障，也没有推断公网 HTTPS 复制失败。

**定位**：`web/frontend/src/sharing.ts` 与 `web/frontend/src/phrases.ts`。

### 6. 桌面主导航依赖用户猜图标（P2，体验判断）

**复现**：正式桌面页面右侧同时排列专栏、文章、动态、片语等图标，默认画面没有可见文字标签。元素有可访问名称，问题是视觉发现性，不是所有图标都没有无障碍名称。

**影响**：初次访问者需要悬停、聚焦或尝试点击来辨认，专栏与文章尤其容易混淆。手机底部导航反而有文字。

**建议**：让主要内容入口常驻短标签，工具操作继续使用紧凑图标。

**定位**：`web/templates/page.html`、`web/frontend/src/dock.ts` 和公共导航样式。

### 7. 112 条游戏没有按名字查找入口（P2，已观察到的能力缺口）

**复现**：正式 `/games` 只有展示顺序、游玩时长、名称排序和平台筛选，没有游戏名称搜索输入；每批 20 项。

**影响**：想确认作者玩没玩某款游戏，需要改排序并逐批翻找；浏览器页内查找也只覆盖当前一批。

**建议**：增加名称搜索，支持与平台筛选组合，并显示命中数量。

**定位**：`web/templates/games.html` 及对应游戏查询处理。

### 8. 公共搜索不能找回已经看到的片语（P2，产品覆盖范围问题）

**复现**：正式 `/phrases` 存在 “Attention is all you need”；进入 `/search?q=Attention` 返回 0 篇文章。当前搜索确实标注了文章／标签范围，这不是文章检索实现失效。

**影响**：产品已经有文章、专栏、动态和片语，用户记得一句话却缺乏跨内容找回路径；文章搜索不能承担完整站内检索任务。

**建议**：提供按内容类型切换的站内搜索，优先补片语、专栏；在结果和空态中明确搜索范围。

**定位**：`web/frontend/src/search.ts`、搜索页面及建议接口。

### 9. 登录恢复提示缺少可执行的下一步（P2，已观察到的能力缺口）

**复现**：正式登录页只有“忘记密码或遗失验证器？请联系站点管理员恢复。”，没有联系入口或恢复说明链接。

**影响**：访客不知道如何联系管理员；站长自己无法登录时，这条提示也不能帮助找到已有的管理员恢复流程。

**建议**：给读者提供配置好的站长联系方式；给自托管站长提供明确的恢复帮助入口。无需把敏感管理操作暴露给匿名用户。

**定位**：`web/frontend/src/components/AuthForm.vue`；与已有账号安全、CLI 恢复文档衔接。

### 10. “保存草稿／留检查点／修订”使用了多套难理解的保存概念（P2，体验判断）

**复现**：隔离站新建文章，输入后约 2 秒显示“已保存”，同时保留“保存草稿”和“留检查点”按钮；点击后仅提示“已创建不可变检查点。”。历史区域又使用“不可变修订”。

**影响**：新作者不容易理解已自动保存后还需不需要点保存、普通保存是否进入历史，以及检查点与发布是什么关系。自动保存本身本轮正常。

**建议**：统一用户术语，例如“已自动保存”“保存历史版本”，并在操作前简短解释历史版本可恢复、不会自动发布。

**定位**：`web/frontend/src/components/MarkdownEditor.vue`。

## 建议顺序与证据边界

优先处理 **1（丢修改）、2（按钮自循环）、4（分页返回）**，随后改善 3 的内容承接和 5 的内网复制体验。6–10 包含发现性、能力覆盖与文案问题，应作为产品改进判断，不统一包装成程序故障。

本机证据目录：`/tmp/painter-ux-review-20261114/`，包含公开页面桌面／手机截图、隔离后台截图，以及 `tasks.json`、`interactions.json`、`followup.json`、`verified.json`。`private/` 中的隔离凭据、浏览器会话和数据库不进入 Git。浏览器仿真不等于物理手机输入法或性能测试。
