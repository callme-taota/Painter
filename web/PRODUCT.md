# Painter 产品约定

## 平台与架构

面向读者、创作者与站长的个人发布系统。Go 模块化单体提供公开页面 SSR、API、身份与后台任务；Vue 3 / TypeScript 工作台提供创作和管理。Tiptap 文档编辑与 CodeMirror 源码共用同一草稿、属性、保存和发布链路。PostgreSQL 18 是唯一数据库，禁止 SQLite；生产不要求 Node、Redis或独立搜索服务。前端仅在构建时使用 Node，资源嵌入 Go 二进制。

当前结构见 [实现架构](../docs/ARCHITECTURE.md)，持久化约束以 `migrations/` 为准。设计基线只说明早期决策，不能代替当前源码与功能合同。

## 用户与主要任务

- 读者：发现和阅读公开文章、图文动态、片语和连载，搜索、关注、收藏、讨论与管理自己的账号。
- 创作者：维护自己的文章 / 动态 / 专栏，上传媒体，明确区分草稿、不可变修订与公开发布。
- 站长：管理网站身份、首页区块、游戏 / 音乐 / 照片 / 项目展示、标签、友链、成员、评论、访问策略和运维。

个人中心默认围绕收藏、关注、足迹；资料、公开主页和安全首次访问时加载，返回保留表单。创作者额外拥有写作任务。公开个人页与私人中心分开，邮箱、电话、收藏和足迹不公开；普通读者不呈现作者空文章列表。

## 内容与阅读

文章、动态、片语是独立资源；动态最多 500 个 Unicode 码点、9 张有序图片，可单独使用文字或图片。标签是唯一分类体系，入口在搜索和文章上下文中。连载专栏是最多 300 篇已有文章的有序引用，公开目录和上一篇 / 下一篇仅包含当前公开章节。

正文 SSR 保留无 JavaScript 阅读和真实 URL。Markdown 卡片使用版本化白名单、安全解析与同一渲染管线，不允许任意 HTML 或运行脚本。图片查看器为无框蒙层，保留关闭、前后切换、Escape 与焦点返回。

提示、指标和摘要是受控组件树的语义模板，v3 组合卡片可复用文本、图片、链接与布局；字段和扩展边界见[正文渲染管线](../docs/CONTENT_RENDER_PIPELINE.md)。文章阅读时长按实际展示正文估算，不统计卡片 JSON 或接口缺失字段。

文章、动态、片语、专栏支持短链接、嵌入 HTML 与专属摘要分享页。分享不授予额外阅读权限，撤回后原入口失效。RSS 默认关闭，由站长设置开启。

## 创作保证

同一草稿、摘要、标签、封面和时间设置服务全部编辑表示。默认直接编辑文档；源码、预览和导出是辅助工具，切换不能丢输入或改变未编辑的 Markdown。

保存使用 CAS、幂等和明确状态；发布指向不可变修订，撤回与恢复旧修订均不隐式发布。加载失败保持锁定并允许重试；冲突保留本地输入，合并后须明确保存。IndexedDB 恢复点按账号隔离；主动退出清理，过期保留后回登录。

显式保存、发布、删除、复制及设置变更共用站内 toast；提示以实际完成结果为准，写入成功但列表刷新失败需分别说明。自动保存不逐次弹成功，错误与恢复只在必要时提醒。表单不嵌入普通操作结果；字段错误、版本冲突、恢复入口、加载失败与重试及安全凭据展示仍保留在具体任务位置。

## 首页与视觉

个人气质来自站长配置的真实身份、介绍、文字和收藏，不生成假履历、统计或供应商认证。首页各区块、顺序、数量、文案和可见性可配置；桌面可连贯呈现个人卡片、项目、发布日历、唱片、游戏与末尾阅读引导。无 JavaScript、减少动态和手机保留自然文档流。

保留原 Painter 标识、黑白灰主色、克制的 Apple 蓝阅读链接、圆头导航与独立工具。明确要求的导航和搜索采用 Liquid Glass；手机使用原生 CSS 模糊 / 底色 / 高光回退，不用随滚动追赶的图片副本。工作台保持紧凑、实色、清晰层级与统一控件。

公开顶栏仅品牌与搜索；内容入口使用侧边 Dock 或手机导航，About 和友链放页脚。全局搜索支持 Ctrl/Cmd+K 和非编辑区斜杠，提供真实建议；筛选只在结果页展示。

## 身份、部署与边界

本地账号为默认登录，可选 GitHub；站长独立控制注册与外部账号访问。TOTP、一次性恢复码、会话撤销和近期验证由同一身份边界实现；其它应用可通过 OIDC Authorization Code + PKCE S256 接入身份。OIDC 身份不自动授予博客业务 API 权限。

以单机和局域网部署为主，支持 HTTPS 代理与 Cloudflare Tunnel。生产 Cookie 与认证页面使用配置中的 HTTPS origin；局域网 HTTP 可用于公开阅读。备份包括数据库、媒体与原始密钥，恢复先进入隔离的新库并验证，再由操作者切换。

[设计规范](DESIGN.md)管理视觉， [全端交互规范](../docs/CROSS_PLATFORM_EXPERIENCE.md)管理手机 / 平板 / 桌面任务。模拟视口、真实浏览器和真实手机验证分别记录，不把它们当成同一种证据。

### 2026-11-14：连续列表与检索

用户确认所有可分页列表采用接近末尾时预加载、自动追加的连续流，不提供页码、上一页、下一页或手动加载更多入口。覆盖公共列表、搜索结果、后台内容与个人列表、评论、展示墙及内容选择器。失败保留已显示内容，提供重试；筛选重置游标，末尾停止请求。章节相邻阅读和图片／唱片等集合内浏览不是列表分页。

桌面公共导航保持纯 icon。内网分享复制降级与登录恢复提示本轮不改。站内搜索覆盖公开文章、专栏、动态与片语，游戏墙另提供名称搜索；标签／作者条件保持文章范围。草稿、撤回、删除内容不进入搜索。

网站信息、功能设置和个人资料的未保存修改需要可见提示及离开保护。没有公开文章时，首页不展示空阅读区，默认阅读号召提供有效的关于页去处；空文章列表返回首页。编辑器区分自动保存、草稿已保存和显式保存历史版本，历史版本可以恢复为草稿，不自动发布。
