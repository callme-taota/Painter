# V12：编辑页焦点与留白

针对用户截图中的整块蓝色正文焦点框、松散的模式 / 格式工具间距，以及宽屏标题下方异常留白，调整既有编辑页样式。仅修改 `editor-layout.css` 与 `DocumentEditor.vue` 的 CSS；不改变编辑事务、保存 / 冲突 / 恢复逻辑、接口、数据库或依赖。

| 部位 | 调整 |
| --- | --- |
| 正文焦点 | 移除覆盖整个正文最小高度的 2px 蓝色 outline；聚焦正文时以格式工具栏底部的主题强调色细线标识位置。强制颜色模式使用系统 Highlight。 |
| 标题焦点 | 使用标题输入自身的底部细线，保留输入光标和文字选区，不再绘制整个输入框外轮廓。其他操作按钮的键盘焦点框保留。 |
| 编辑模式 | 当前模式改为文字与 2px 下划线，不使用大块蓝底；按钮仍为至少 44px 操作目标。 |
| 垂直间距 | 桌面标题最小高度由 108px 缩至 92px，手机由 90px 缩至 80px；同时收紧标题、模式、格式工具及正文起始内边距。 |
| 宽屏属性栏 | 第一行按标题固有内容定高，第二行承载写作区；属性栏使用 size containment 并独立滚动，使其跟随写作高度，不参与撑大标题行或形成末尾空白轨道。 |
| 文本边距 | 保留标题 / 正文最大 850px 文本容器，32 / 28 / 18px 配对左右内边距；源码、窄屏披露及单份属性控件保持原有结构。 |

原实现实测标题元素只有 109px，但跨行属性栏把网格首行撑至约163px或241px，在标题后多出约54px或132px空隙。最终宽屏与高屏测试中，标题面与模式栏之间的额外间距均为0，属性栏也不再造成写作区域之后的空白网格行。

## 验证

- 四种尺寸（1920×1080、1440×1400、900×1000、390×844）、浅深主题，91 项焦点、文字选区、布局、44px 目标及无横向溢出检查通过；包括强制颜色焦点检查。16 张最终截图覆盖空稿聚焦与已有正文选中。[报告](../tests/artifacts/v12/visual/report.json)
- 复用173项只读编辑页布局与交互检查，以及43项V11编辑安全检查；均通过，未发出真实内容写入。[布局](../tests/artifacts/v12/layout/layout.json)、[编辑保护](../tests/artifacts/v12/editor-safety/report.json)
- Vue类型检查、Vite与嵌入前端的Go release构建通过；一次针对两个修改文件的静态检测无发现。没有后端改动，本轮不重跑数据库业务测试，也不声称新增业务能力。
- 视觉检查使用Chromium尺寸模拟，未声称实体设备或屏幕阅读器认证。构建、独立审阅、实际切换和数据保持结果见[验收](VALIDATION.md)与[汇总](../tests/artifacts/v12/summary.json)。
