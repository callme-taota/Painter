# V6：标签选择与相关推荐

2026-10-28。在现有Go单体和PostgreSQL上迭代，无新增迁移、运行服务或依赖。

## 编辑器选择标签

“文章信息与展示”中的标签改为可搜索的多选输入框。点击或聚焦后展开已有标签，点选/Enter添加，已选项作为带移除按钮的标签显示；再次选择已选项也能移除。支持↑/↓、Escape、外部点击关闭、中文输入法确认和全角大小写规范化搜索。搜索词仅是本地界面状态，不触发草稿保存，也不创建新标签。

最多选择20个，达到上限后未选项明确不可选；归档或暂不可用的已有选择仍保留ID，显示说明并允许明确移除。没有可选项或搜索不匹配时提供继续操作的文案。所有操作使用原 `draft.tag_ids` 与原保存/恢复/检查点/发布合同，metadata-only仍保留Markdown原串。站点标签管理入口不变。

实现为独立 `TagPicker.vue`，44px交互目标，使用已有浅/深语义色；combobox通过active descendant指向多选listbox，选项标记aria-selected，界面不再使用标签复选框。文章时间的三个布尔开关继续使用复选框。

## 文章末尾推荐

文章的互动/讨论区域之后显示“相关推荐”，最多三篇；没有其他公开文章时不显示整个区块。服务端直接渲染，关闭JavaScript仍可阅读和打开。

`RelatedPosts`在一个只读SQL语句中取当前公开文章与候选：相同规范标签的数量降序，再按当前发布时间、文章ID降序；没有足够相同标签的文章时，剩余位置按最近发布补齐。历史标签别名使用已有 `effective_revision_tags` 映射，不改写修订。自己、草稿、撤回和回收站中的文章不进入结果。公开内容沿用现有 `public_posts` 可见性合同，封禁账号并不自动撤下其历史公开内容。

标题、摘要、封面、标签与时间选项都从当前公开修订投影读取；私有编辑不会改变推荐关系或泄漏新的标题/标签。日期显示遵守各文章已发布的选项。列表使用开放分隔行、可选封面、标题链接和元信息，保留右侧工具的空间；无封面文章直接显示文字。

本轮不新增个性化画像、推荐点击事件、对外推荐API或离线推荐任务。数据库不新增写入；现有页面/阅读埋点及文章链接导航继续生效。

## 验证与发布

真实PG的两个新集成测试（含race）覆盖排序、同时间ID排序、补齐、别名、私有修改隔离、重新发布及公开可见性。候选真实浏览器23项通过，离线保存8项及新稿恢复9项通过；空标签列表的呈现单独使用隔离响应，不作为真实数据库写入证明。三个尺寸、浅深主题共18张截图无溢出或脚本异常。详见 [验收记录](VALIDATION.md) 与 `tests/artifacts/v6/`。

升级保留正式原数据库、媒体与配置，仅替换嵌入前端的Go程序；候选QA库不会覆盖原数据。当前地址及运维方式见 [LAN_ACCESS.md](LAN_ACCESS.md)。
