# RSS 订阅

订阅地址为站点根地址下的 `/rss.xml`，例如 `https://blog.example.com/rss.xml`。把这个地址添加到支持 RSS 的阅读器即可订阅。公开页面最底部提供 **RSS** 链接，HTML head 同时提供标准的订阅自动发现链接。

## 内容范围

- RSS 2.0，提供最近 20 篇公开文章的标题、摘要、原文链接和发布时间。
- 按首次发布时间倒序排列，同一时间按文章编号倒序排列。
- 文章原文链接同时作为稳定 GUID；重新发布仍是同一篇文章。
- 只读取当前发布修订。编辑草稿、保存检查点和恢复草稿不会改变订阅内容；明确重新发布后更新摘要。
- 草稿、撤回和已删除文章不会出现在当前订阅源中。阅读器已经下载的内容由各阅读器自己保存，站点无法远程清除。
- 本轮只订阅文章，动态、片语、产品和按作者或专栏筛选不包含在此订阅源内。

## 后台开关

站长打开 **站点设置 → 功能与通知 → 开启 RSS 订阅**，保存后立即生效。关闭时，订阅地址返回 404，页脚入口与自动发现链接同时隐藏。新安装仍保留默认关闭的配置，由站长决定是否开启。

订阅不要求登录，不包含账户信息或草稿。站点标题与说明来自网站配置；说明优先使用“一句介绍”，留空时使用搜索摘要，再留空时使用站点名称。

## HTTP 与部署

成功响应为 `application/rss+xml; charset=utf-8`，支持 GET、HEAD 和基于 ETag 的条件请求。阅读器内容未变化时得到无正文的 304；关闭开关或撤回文章后会重新判断当前内容，不复用旧的条件命中。关闭和服务异常响应使用 `no-store`。

无需后台定时生成、额外服务或数据库迁移。内网与 Tunnel 共用同一个订阅接口；feed 中的原文地址和 Atom self 地址使用服务器配置的 `PUBLIC_BASE_URL`，不会使用访问请求的 Host。公开订阅应使用外部站点地址。

运维时不要为 `/rss.xml` 设置 Cloudflare “Cache Everything”或覆盖来源缓存规则。保留来源的 `Cache-Control: public, max-age=0, must-revalidate`，让阅读器在刷新时重新验证。
