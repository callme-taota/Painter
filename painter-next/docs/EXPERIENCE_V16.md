# V16：连续写作、表格管理与作者主页

这一轮保留 Painter 的纸墨蓝、原 Logo 和现有数据链路，重点解决编辑割裂、管理效率与阅读层次。当前访问地址沿用 <http://192.168.2.209:18080>。发布结果与数据库保留核验见 `tests/artifacts/v16/promotion.json`；不向正式数据库复制验收夹具。

## 编辑与后台

文章默认直接编辑文档，Markdown 源码及导出收进“更多”。切换只影响正文表示：摘要、标签、封面、时间选择始终是同一份控件，位置和展开状态一致。宽屏使用280px右侧信息栏，窄屏使用标题下的折叠区。标题、工具栏和正文统一850px阅读边界；长标题自动换行，不在单行输入框里截断。源码行号正常占据左侧留白，避免遮住Markdown前缀和首字。

参考了 [WordPress 的内容工作区与设置组织](https://developer.wordpress.org/block-editor/explanations/user-interface/)以及 [Ghost 的文章设置](https://ghost.org/help/post-settings/)，采用“内容为主、属性辅助、技术入口次要”的层级。没有引入外部编辑服务或改变原有保存模型。编辑器详情见 [editor-v16.md](editor-v16.md)。

文章管理改为表格：标题/摘要、作者（全站范围）、状态、更新时间与操作；每页20条，支持标题/摘要服务端搜索、状态和本人/全站筛选、前后翻页、编辑、撤回、回收与恢复。搜索游标绑定关键词和权限范围，普通作者不能读取全站草稿。它不是正文全文检索。

标签管理也改为表格，支持在完整已载入标签集中搜索名称/说明、按归档状态筛选、新建、单行展开编辑。一次只出现一个表单，归档保留文章关系。窄屏表格在容器内横滑并显示提示，操作列可滚动到达；操作菜单不会被表格裁切。没有新增批量删除或改变标签接口并发语义。

后台 Painter 悬停区域改为对称的上下内边距，名称、Logo和副标题共同居中。“评论治理”改为“评论管理”：个人博客仍需要隐藏不当评论和恢复误隐藏内容，因此保留这些实际操作，不增加审批流程。公共顶部导航圆角提高至桌面24px、手机20px。

## 作者与阅读

作者页的头像、名字、关注按钮在同一行居中，简介移到下方；作者文章搜索直接提交到自己的 `/users/{id}?q=…` 页面，包含SSR结果和签名分页，无JavaScript也可使用。路径作者强制限定查询，不能通过参数串到另一作者。

在“个人空间 → 个人资料 → 作者主页”可选择四种背景配色、上传/替换自己的图片、移除图片和预览后保存。背景使用独立版本，修改联系方式不会覆盖主页背景。失败保留输入；并发冲突要求重新读取；离开时保护未保存修改。

评论区域使用一个有柔和投影的实色纸面，评论身份、日期、正文和操作形成清晰层级；评论行不再叠一层层卡片。加载、空列表、登录提示和失败可辨认。删除评论使用项目统一确认框，发表评论、点赞、删除继续走原有权限接口。

首页“最近写下的”向后留出空间，改用大幅保存封面的横向展架。桌面在向下滚动时依次推进封面；手机、减少动效和无JavaScript使用原生横向浏览。真实空站点保持空态，不灌入样例文章。正式环境当前没有公开文章，因此不会展示隔离验收中的六张测试封面。

## 数据与运行

0014新增 `author_page_profiles`：用户主键、受限配色、可空媒体外键、独立版本、更新时间。只新增表和索引，不改历史文章、用户或配置。私人GET/PUT `/api/v1/me/author-page` 使用现有会话、CSRF、If-Match、幂等和审计；只允许自己的ready本地媒体，不接受任意CSS或远程URL。

保存与媒体删除/GC使用锁互斥；被背景引用的图片不能删除。公开访问只展示有效作者的ready背景，DTO不含联系方式。完整数据库与媒体备份包含主页背景；测试实际执行了pg_dump及隔离恢复验证。运行架构仍为单Go程序和PostgreSQL，无SQLite或新服务。

更新前的完整私有备份为 `/tmp/painter-next-before-v16-final-20261102`。其中 `runtime/painter-v15-schema14` 是保留旧界面、识别schema14且包含新背景引用保护的回退程序，已在隔离服务做17项实际验证。原只认识schema13的V15程序不能直接运行于升级后的数据库；不得用旧备份覆盖期间产生的新数据。当前LAN仍使用临时systemd与`/tmp`配置/数据，持久部署应采用既有Compose工具，见 [部署维护文档](deployment-tool.md)。
