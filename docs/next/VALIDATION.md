## 2. 可复现入口

验证脚本、运行环境要求与固定Go驱动探针位于 [validation目录](validation/README.md)。脚本仅在新建的隔离数据库 / 临时实例中运行，不可拿生产连接字符串执行；正式升级由专用迁移runner完成。

52项验证包含顺序SQL与真实两连接竞争；它不等同于全部应用集成测试。SQL验证中的GIN计划只验证索引可选路径，不是10万级中文数据上的自然计划或p95证据。性能验收必须另用真实规模、自然优化器选择和混合负载测量。

## 3. 已覆盖的关键反例

- 草稿独有内容不进入公开视图与搜索；发布后继续保存不改变线上修订。
- 不可变修订及子快照不能修改或补写；孤立延迟外键不能提交；跨文章revision发布被拒绝。
- 发布指针、搜索投影与generation共同提交 / 回滚；撤回和软删除关闭公开入口。
- staging图片不可引用；ready字节元数据不可变；新增引用与GC争同一媒体行锁，后执行者重新核对状态 / 引用。
- 两连接保存同一旧版本只有一个成功；持久client_draft_id阻止超出幂等窗后重复创建。
- 两个owner并发降权仍留下有效owner；管理变更与普通写命令遵守共享 / 排他权限屏障。
- 业务消费收据与日报共同回滚，重放不会重复增加本地指标。
- 自增seq与提交顺序不同仍不漏聚合；认领回滚可恢复，指标和aggregated标记不会只提交一半。
- 恢复到新库后表行数、公开内容、中文搜索与修订不可变约束可用。
