# 正文组合卡片渲染管线

Painter 使用 Markdown 承载正文，并以 `painter-card` JSON 围栏保存卡片。v3 `layout` 提供受控组件组合；指标、摘要和提示是这套组件的语义模板，不需要为每一种相似展示新增业务渲染器。它是本项目的轻量组件树，不是 A2UI 的消息、Surface、数据绑定或交互运行时。

## 输入与版本

- v1：GitHub、Steam、Apple Music、网页参考、动态与片语引用，保留原有专用语义及权限规则。
- v2：提示、指标、摘要，保留原有字段与编辑表单，内部编译为组件树。
- v3：`{"v":3,"type":"layout","root":{...}}`，直接表达受控组件组合。
- 整篇导入仍为 `painter.article` version 1，`card` 区块可以包含上述三个卡片版本。

完整字段与限制见 [JSON Schema](painter-article.schema.json)、[导入说明](ARTICLE_IMPORT.md)，可运行示例见 [组合示例](examples/painter-article.json)。卡片版本和文章导入版本互相独立。

## 组件目录

`panel` 是根表面；`grid` 是自适应的条目布局；`stack` 按阅读顺序组合内容；`text` 提供标题、标签、强调数值、正文、说明五种角色；`link` 展示来源或跳转；`image` 引用已上传媒体。

组件只描述含义与结构，具体颜色、字号、间距、圆角、深浅主题与手机列数由 Painter 控制。文本角色使用段落，不向正文目录加入标题。网格只接受 `stack`；根表面不能嵌套，避免出现多层套卡。

## 处理流程

1. 文档编辑器或 AI 导入提供版本化卡片；编辑器仍可使用“提示”“指标”“摘要”等语义表单。
2. 服务端严格验证 JSON、类型、字段、文本、链接、节点数、深度及媒体引用。
3. v2 模板编译成组件树，v3 直接使用校验后的树；同一个节点遍历器生成 HTML。
4. Goldmark 正文与卡片生成结果统一经过 HTML 白名单清洗，输出规范 HTML、可检索纯文本、目录、媒体引用、内容哈希与渲染器版本。
5. 预览、草稿检查、检查点和发布使用这条共同管线。发布 HTML 作为不可变修订快照保存；公开页面直接 SSR，无 JavaScript 仍可阅读卡片。
6. 编辑器用对应的组件遍历器呈现文档节点，并可序列化回同一份 Markdown。客户端校验服务编辑体验，服务端验证是最终权威。

现有 v1 外部参考继续保存受控快照；动态和片语只保存引用编号，读取时检查当前公开状态。组合卡片不提供绕过这些权限边界的通道。

## 如何新增展示模板

“指标”是标签、强调数值、说明和来源的组合；“摘要”是标签和正文的组合；混合模板可以把两种条目放进同一个网格。这样的模板只需提供合法的 v3 数据和编辑入口，不需要再增加一种 `type`、一套服务端 HTML 和一套客户端渲染分支。

只有出现新的基础能力，例如图表或受权限控制的业务动作，才新增组件。新增基础组件时需要同时提供：精确 JSON 合同与限制、服务端校验及 SSR、编辑器渲染与往返、样式及无障碍处理、安全和兼容测试、导入 Schema 与 AI 提示词。不会从文章中下载或执行组件代码。

## 安全与资源边界

每卡最多 8 KiB、64 个节点、6 层（根为 1）、6 张图片；每文最多 128 张卡片和 1 MiB Markdown。节点没有任意 CSS、类名、ID、HTML、脚本、事件、函数、数据绑定、网络请求或发布指令。所有层级拒绝未知字段、重复字段与 `null`。

文字按纯文本转义；来源链接沿用公开 HTTPS 检查；图片只接受 `/media/真实编号`，纳入原有 ready 状态、使用权限与修订媒体引用检查。组合卡片本身不会访问外部服务。

## 旧文章与后续协议

保留旧版本的数据和显示语义；v2 编译器输出与原有模板相同的 HTML 结构及样式角色。渲染器版本追加新能力标记，新预览与发布使用新管线；既有不可变修订不因部署而回写或自动重新发布。

普通文章遇到未知版本或类型时保留可读代码围栏；明确识别的非法卡片报错。结构化导入直接拒绝未知卡片，避免把损坏内容静默当作成功导入。

若以后接入 A2UI，应新增明确版本与组件目录的适配器，把可支持的描述映射到此组件树。其交互、函数和数据绑定必须另行实现并授权；目前不声称能运行任意第三方 A2UI 卡片。

## 阅读时长

文章页从当前实际展示的公开 HTML 提取文字，而非依赖缺失的接口字段或统计 Markdown/JSON 源码。中文等 CJK 文字按字符、英文等按单词累计估算，过滤链接地址、HTML 属性与非正文节点，向上取整且至少显示 1 分钟。代码中的可读文字参与估算；语法符号、标签与样式不充当自然语言单词。

这是阅读参考，不是精确计时。站内引用仍使用当前可公开的内容，撤回内容不会为了估算时长重新读取或泄漏。
