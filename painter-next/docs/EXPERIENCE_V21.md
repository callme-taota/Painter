# V21：动态图片与原图浏览

本轮为独立动态增加图片。可以只发图片，也可以配最多500个 Unicode code points 的文字；没有图片时仍须填写非空白文字。V20 的动态列表 / 双列 / 多列布局、后台权限和可选创作入口继续沿用。

## 图片与上传

每条动态最多9张有序图片，格式为 PNG、JPEG、GIF 或 WebP，保存时须处于 `ready` 状态。每张图片可填写最多200个 Unicode code points 的说明；文字和说明均按 code points 计数，不按 UTF-16 长度或视觉组合字符计数。空格与换行同样计入文字限制。

编辑器从私有列表读取服务端 `max_images` 和 `max_image_bytes`；当前数量上限为9，单图字节限制随部署配置，缺省回退为10 MiB。浏览器的格式、大小和数量检查用于及时提示，服务端仍执行完整校验。

- 「添加图片」支持一次选择多个文件，按选择顺序逐个上传。每项显示缩略图、等待 / 上传中 / 完成 / 失败状态，上传中使用不虚构百分比的进度提示。
- 一张失败不会清空其它成功图片。失败项保留当前页面中的原始文件与幂等键，可重试；排队项和失败项可取消。保存前须完成上传，或明确取消失败项。
- 「前移 / 后移」按钮调整顺序，所有操作可用键盘。图片说明收在原生折叠项中，摘要显示已有说明或添加入口；超出200字符时展开并提示修正。
- 上传期间禁止切换条目、保存或发布。未保存保护、冲突比较和不确定新建重试的原始请求，均包含文字、图片顺序和说明。

文件重试队列只存在于当前页面，不是跨刷新离线恢复。临时缩略图的 object URL 在完成、移除、替换内容或卸载时释放。上传成功不等于保存或公开，也不自动附到其它文章或动态。

## 草稿、发布与媒体引用

草稿图片和公开图片使用独立引用。保存只更新草稿；显式发布才把当前文字和有序图片复制为公开快照。因此，编辑已发布动态的文字、增减图片、重排或修改说明，都不会提前改变公开版本。

撤回或软删除清除公开文本及公开图片引用，草稿及其图片引用仍保留；软删除记录在后台仅供查看，没有恢复入口。从编辑器移除一张图片只改变该动态的引用，不调用物理媒体删除。草稿引用（包括软删除条目）与公开引用都受媒体 GC 保护。未被内容引用的上传沿用既有7天孤立资源清理策略，不承诺点击「移除」后立即释放磁盘。

站长 / 作者权限沿用 V20：作者只能管理自己的动态，站长可管理全站。新加入的图片须符合媒体归属和可用状态要求；已附在动态上的图片允许依照权限保留、重排和编辑说明。公开接口只返回当前发布的图片，不泄露未发布草稿图片。

## 公开阅读与原图查看

公开动态列表与详情由 SSR 输出完整文字、图片说明和图片链接。单图使用 `object-fit: contain` 保留完整构图；多图按图片数量使用一、二或三列，四张为2×2，顺序与保存顺序一致。这是卡片内部的图片排布，不改变 V20 动态卡片本身的布局偏好。

每张图片保留指向原图的普通链接，无 JavaScript 仍可打开。增强后使用键盘可操作的原生对话框查看图片，显示当前位置 / 总数，提供上一张、下一张、打开原图和关闭；支持方向键与 Escape，关闭后焦点返回触发图片。

照片按原上传资源懒加载，不引入额外缩略图处理服务、图片 CDN 或新的运行时依赖。

## 数据与接口兼容

schema16 新增关系表 `moment_images`，区分草稿 / 公开引用、顺序与说明，并有数据库约束保护。写入继续使用现有 CAS、幂等键、权限检查、CSRF 和审计事务。

创建或保存草稿提交 `{text, images:[{media_id,alt}]}`。私有响应分别提供 `images` 与 `public_images`，每项包含 `media_id`、`url`、`alt`；公开响应只提供公开的 `images`。兼容旧客户端保存时的规则为：省略 `images` 保留已有草稿图片，显式 `[]` 移除全部，`null` 拒绝。公开快照的替换仍须单独发布。

## 范围与验证状态

本轮只扩展动态图片。收件箱、私信、分享、系列、动态点赞 / 评论及跨内容媒体库选择器仍不在范围内；文章编辑器、V20 卡片布局和按场景配置的创作工具不另行改造。

已完成构建、迁移并部署到局域网服务：[动态页](http://192.168.2.209:18080/moments)、[动态管理](http://192.168.2.209:18080/studio/moments)。正式数据库升级到 schema16，21类既有业务集合、媒体文件与环境配置核对一致；验收图片和动态仅保留在隔离候选库，没有导入正式库。

实际验证：TypeScript/Vite 与 Go 构建、`go test ./...`、`go vet ./...` 通过；28项动态与 SSR 目标测试在真实临时 PostgreSQL 库下通过 race 检查，包含12项新增图片测试。独立源码审查发现的事务内额外借连接问题已修复为复用当前事务，并通过双连接池下的受控并发回归。候选浏览器97项检查、正式环境61项只读检查通过；13张实图独立评审结论 ship，3张技术重采用于等待图片解码及定位手机编辑视口，新组件检测无发现。
