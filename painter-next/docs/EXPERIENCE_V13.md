# V13：阅读页与滚动导航

按照阅读顺序重排既有文章模板，保留 Painter 的字体、纸面主题、真实作者、渐变封面与已发布内容。没有新增依赖、业务接口或数据库迁移。

| 部位 | 当前行为 |
| --- | --- |
| 文章首屏 | 标题 → 摘要与标签 → 封面 → 正文。阅读时长和信息按钮位于标签行右侧。封面与正文共用最大760px宽度，保留原图比例。 |
| 时间信息 | 三种时间收进一个带可访问名称的圆形 i 按钮，点击或键盘展开。仍遵循每篇文章已保存的创建 / 最后编辑 / 发布时间开关；全部关闭时不显示按钮。未知最后编辑时间仍为“未记录”。 |
| 作者 | 宽屏独立放在右侧，与目录共用辅助栏；1050px及以下在封面前右对齐显示。只渲染一份作者，头像和名字连接真实作者页。 |
| 分隔关系 | 正文 Markdown 分隔符为居中短线；讨论区使用正文宽度的边界；相关推荐使用独立浅底区域，条目之间通过留白区分，不重复横线。 |
| 顶部栏 | 首页保留原有行为。其他公开页面和手机工作台下滚累计32px隐藏，上滚12px出现，到页面顶部总是显示。隐藏只移动绘制位置，保留文档空间，避免跳动。桌面工作台沿用侧栏。 |

时间按钮使用原生 `details/summary`，关闭时不占正文高度，禁用 JavaScript 仍可展开。增强脚本支持点击外部或 Escape 关闭；全局搜索弹窗打开时由搜索处理 Escape。保留原有日期开关及 JSON-LD 的日期过滤，没有把原来关闭的时间重新公开。

顶部栏隐藏时同时退出键盘焦点序列；Tab 会先恢复导航。焦点在导航内、菜单或模态对话框打开时保持可见，兼容页面恢复、视口变化和减少动画偏好。没有 `inert` 支持或禁用 JavaScript 时保留可见导航。手机编辑页在顶部栏返回时同步避让保存操作。

## 验证

- 阅读175项：1440 / 900 / 390 / 320px、浅深主题，覆盖首屏布局、原生时间展开、键盘 / 触控 / 无JS、真实作者和推荐链接；另以DOM呈现模拟缺少可选内容的1024px布局。没有通过模拟响应宣称真实持久化。[报告](../tests/artifacts/v13/reading/report.json)
- 导航104项：文章、标签、片语、搜索、关于、登录、注册、安装和手机工作台，包括上下滚动、微小抖动、回弹、焦点、搜索 / 菜单 / 抽屉保护、首页例外和减少动画。[报告](../tests/artifacts/v13/header/report.json)
- 编辑页91项既有焦点 / 选区 / 留白回归通过。[报告](../tests/artifacts/v13/editor-regression/report.json)
- PostgreSQL 18.6全套90个顶层测试及14个子测试通过，没有跳过的测试。本轮新增8种时间开关组合的真实SSR测试。[后端汇总](../tests/artifacts/v13/go-test-summary.json)
- Vue类型检查、Vite与CGO禁用的Go release构建通过。一次静态检测对未关联外部CSS的Go模板报告默认16px层级和黑色，按实际主题、计算尺寸及渲染判定为误报；未新增忽略规则。[检测](../tests/artifacts/v13/detector.json)
