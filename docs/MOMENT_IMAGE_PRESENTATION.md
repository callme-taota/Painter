# 动态图片与卡片展示规范

适用范围：动态列表、作者页的动态卡片，以及它们打开的公开详情。桌面多列、手机双列沿用相同图片规则。

## 列表预览

- 图片区固定为 **4:5**，图片铺满圆角边界，无内边距、相框或补色条。使用 `object-fit: cover`，不拉伸图片。
- 第一张图片是封面。列表只加载这一张，其他图片通过张数提示，在详情中按原顺序展示。
- 普通图片中心裁切；超长竖图展示顶部。原图文件与数据库中的图片顺序不因裁切而改变。
- 图片尺寸尚未得知时先使用中心裁切，容器比例始终稳定。浏览器加载后按其实际解码方向判断长宽，兼容 JPEG 方向信息；不通过列表接口额外请求尺寸。

| 原图类型 | 判定 | 列表取景 | 裁切示例 |
| --- | --- | --- | --- |
| 4:5 竖图 | 宽 / 高 = 0.8 | 完整铺满 | 无比例裁切 |
| 方图 | 宽 = 高 | 居中，裁掉左右边缘 | 保留约 80% 原图宽度 |
| 横图与全景 | 宽 > 高 | 居中，裁掉左右边缘 | 16:9 横图保留约 45% 原图宽度 |
| 普通竖图 | 高 ≤ 宽 × 2 | 居中，按比例裁掉上下或左右 | 9:16 竖图保留约 70% 原图高度 |
| 超长竖图 / 长截图 | 高 > 宽 × 2 | 顶部居中，保留开头内容 | 1:3 长图预览约 42% 原图高度 |

缩放系数为 `max(容器宽 / 原图宽, 容器高 / 原图高)`。普通图将多出的部分两侧均分；超长竖图的纵向裁切从顶部开始。分类和取色采用同一裁切区域，避免扩散颜色与实际封面脱节。

## 底部材质与颜色扩散

- 图片始终是主体。文字在图片底部，桌面最多三行、手机最多两行，完整正文在详情阅读。
- 文字下方使用局部毛玻璃，覆盖图片底部约 44%，向上渐隐；纯图片卡片保留约 22% 的薄玻璃。纯文字卡片继续使用中性底色。
- 扩散颜色来自当前封面可见区域的下缘，左右分别取色，只在图片下缘形成柔和阴影，不给整张卡片加持续变化的光晕。
- 每张封面加载后最多进行一次 **24 × 8 像素**的本地采样；复用已加载图片，不上传像素，不另取图片，不绑定滚动或逐帧动画。
- 取色失败、画布不可用、跨域限制或透明图片无有效颜色时，立即保留中性材质，文字与图片入口继续可用。图片加载失败时隐藏玻璃与扩散，显示现有失败提示。
- 减少透明度和高对比模式移除模糊与扩散，文字切换为清晰实色。没有 JavaScript 时保留默认裁切、底部材质与真实详情链接，不依赖增强代码才能阅读。

## 详情与原图

列表是预览，详情用于看完整画面：桌面左侧图集、手机横向图集均使用 `contain`，不继承列表裁切。比例不同产生的剩余空间使用站点中性底色，不拉伸或复制图片填充。

图片预览继续展示完整原图，保留前后切换、关闭、键盘和原生图片链接；分享 URL 指向公开动态，不能改变图片的访问权限。

## 发布图片建议

优先选择 **4:5** 首图，例如 960 × 1200。主体尽量放在中央，底部约三分之一避免放重要文字、人脸或必须完整展示的细节。横向作品、海报与长截图可以正常发布，但应通过详情查看完整内容。

目前没有自动识别人脸、主体追踪或作者自定义焦点。后续如增加焦点坐标，应同时用于裁切、取色和创作预览，而不是分别计算。
