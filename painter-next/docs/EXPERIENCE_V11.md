# V11：编辑保护与资源状态

本轮修复上一轮检查确认的七条异常路径，保留 V10 的页面布局、编辑器、账号体系和数据模型。没有新增数据库迁移、依赖或独立服务，仍为嵌入前端的 Go 单体与 PostgreSQL 18，schema 为 12。

| 问题 | 修复后的行为 |
| --- | --- |
| 编辑器初始化失败仍可写入空稿 | 标签与现有草稿完整加载并校验之前，标题、正文、属性、保存和发布均锁定。失败可重新加载；错误的 200 / 非 JSON 响应也不能解锁。初始化失败不写恢复点、不发送草稿命令。 |
| 采用服务器基准后自动覆盖冲突内容 | 保留两份内容对照，暂停定时、输入完成、联网、排队与间隔自动保存。只有明确点击保存或使用保存快捷键，且最新修改得到确认，才结束合并状态。发布与检查点等待合并保存。手动合并标记及对照快照进入浏览器恢复点，内容相同的恢复点也保留该标记。 |
| 恢复历史期间输入被替换 | 先提交文档编辑器待提交事务，锁定标题、两种正文与全部属性，保存当前修改后再恢复。恢复请求和后续读取期间均保持锁定；失败或数据不完整时保留本地内容，提供导出和重新读取入口。重读不会再次发送恢复命令；公开版本保持不变。 |
| 搜索建议触摸滑动 / 右中键误跳转 | 移除 pointerdown 导航，建议项使用真实链接原生激活；触摸滚动不跳转，右键、中键和修饰键保留浏览器语义，键盘上下选择及 Enter 保留。 |
| 已删除媒体仍列出并提供无效操作 | 查询在分页之前排除 deleted；仍只返回当前账号媒体。只有 ready 提供预览；仅未被引用的 ready / failed 项可删除，其余状态明确显示并禁用删除。 |
| 已删除评论展示无法执行的恢复按钮 | deleted 显示“已删除，无法恢复”；visible / hidden 才提供隐藏或恢复可见操作，服务端的永久删除约束保持不变。 |
| 旧片语冲突重载只能从第一页找 | 新增站长专用精确 GET，按当前 ID 获取最新版本，无须重载列表或丢弃已加载分页。加载期间锁定编辑表单及切换操作；503、404、格式异常均保留本地输入；只有合法响应才替换内容与 CAS 版本。 |

## 数据与时序

现有草稿仍使用文章版本与草稿版本双重条件写入，命令保留幂等键。新稿找回仍按 client draft ID 映射，避免首次创建响应丢失后重复创建。历史恢复仍由后端事务生成 before_restore 检查点并更新草稿，不直接改变公开指针。

浏览器恢复记录新增 `manual_merge_required` 与普通 JSON `conflict_snapshot`。它们只保存在当前账号、当前 origin 的 IndexedDB；不新增服务器表，也不跨设备同步。合并标记不会因为刷新页面或正文与服务器相同而被过滤；用户选择加载后继续遵守手动保存要求。

新增读取接口为 `GET /api/v1/admin/phrases/{id}`：仅 owner 可读，非法、越界及不存在 ID 为 404，响应为既有片语 DTO，使用 `Cache-Control: private, no-store`。公开片语范围未扩展，修改仍要求版本条件。

## 验证与交付

专项异常路径使用请求拦截模拟加载失败、409、慢响应、恢复后读取失败、格式错误及触摸滚动，不提交真实业务写入。实际文档生命周期、离线 / 慢响应恢复和丢创建响应测试只在独立克隆库执行；测试发布已撤回，不把 QA 库复制到正式环境。

完整结果、截图、独立审阅和切换记录见 [验收](VALIDATION.md) 与 [汇总](../tests/artifacts/v11/summary.json)。当前局域网入口继续使用 [原地址](http://192.168.2.209:18080)。后台通用表单改进、账号生命周期、持久部署与 ButtonAuth 不属于本轮七项修复。
