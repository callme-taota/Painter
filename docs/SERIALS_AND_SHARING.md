# 连载专栏与三层分享

在现有 Go 单体、PostgreSQL 18、Go SSR + Vue 工作台中实现，不增加常驻服务。普通阅读保持真实 URL 和服务端渲染；管理编排使用有权限的 API。

## 使用入口

- 读者：`/series` 查看公开专栏，`/series/{id}` 查看目录。文章末尾显示所属专栏与上一篇 / 下一篇。
- 创作者：内容管理 → 专栏管理（`/studio/series`），创建专栏、添加已有文章、上下调整顺序、上传封面、选择连载 / 完结与草稿 / 公开。
- 分享：文章、动态、片语、专栏的“分享”入口。首次打开才请求分享信息，切换三种方式不会重复请求。

专栏是有序的文章引用。每个专栏最多 300 章，同一文章可属于多个专栏。添加草稿不会自动发布文章；专栏公开后，读者只能看到已发布的章节。删除专栏保留文章；删除文章后管理页提示移除失效章节，避免保存时无法定位错误。

“连载中 / 已完结”是创作状态，“草稿 / 公开”是可见性，两者独立。当前不包含章节付费、专栏订阅通知、自动发布日程或跨作者联合编排。

## 分层与数据

| 层 | 实现 | 职责 |
| --- | --- | --- |
| 页面 | `web/templates/series.html`、`page.html` | 列表、目录、文章连续阅读，SSR 输出首屏与分页链接 |
| 管理交互 | `SeriesManager.vue` | 搜索、选择文章、排序、完整提交、冲突与未保存提示 |
| 应用模块 | `internal/app/series.go` | 角色、资源归属、公开投影、事务与版本控制 |
| 分享模块 | `internal/app/sharing.go`、`sharing.ts` | 解析当前公开资源、签名 URL、独立摘要页、嵌入卡片 |
| 数据约束 | `migrations/0024_serial_columns.sql` | 外键、唯一顺序、不可转移作者、媒体归属、版本递增、审计动作 |

新增数据库版本为 **24**：

| 表 | 关键字段与约束 |
| --- | --- |
| `series` | bigint ID、作者 FK、version、title 1–120 字、slug 活跃唯一、description ≤1200 字、封面媒体 FK、status、state、创建 / 更新 / 软删除时间 |
| `series_chapters` | series_id + post_id 联合主键；同一专栏 position 唯一且为 1–300；文章 / 专栏 FK；post_id 反向索引 |

文章正文仍只在既有草稿 / 发布修订体系中存储。专栏不复制正文、不建立另一套发布快照。封面只能引用作者自己已完成上传的 ready 媒体；媒体引用检测和清理包含专栏。删除专栏会清空封面引用与章节关系。

## 写入与业务时序

创建 / 更新流程：校验请求格式 → 会话、角色、Origin、CSRF、幂等检查 → 锁定专栏（更新时）→ 比对 If-Match → 按文章 ID 排序锁定引用文章 → 校验同一作者且未删除 → 校验并锁定封面媒体 → 写入专栏与完整章节数组 → 审计与幂等结果一起提交。任何一步失败整笔事务回滚。

- **PUT 是完整替换**：调用者必须提交全部 `chapter_post_ids`，缺省或空数组会清空目录。管理界面始终发送完整数组。
- 缺 If-Match 返回 428；旧版本返回 409，保留当前表单。不可用第三方文章或封面替换专栏作者。
- 同一幂等键重放不重复创建 / 重排。更新和删除版本只递增一次。
- 专栏详情在一条 SQL 的 MVCC 快照中读取元数据与公开章节。文章导航也只关联当前 `public_posts`，不读取私人草稿标题。
- 文章撤回 / 删除提交后，下一次专栏读取、导航和分享都会检查当前公开状态。原始章节编号保留，隐藏章节不造成暗中重排。
- 停用账号沿用既有内容政策：已发布文章及专栏仍公开，公开个人页和账号操作不可用。要撤回内容应显式撤回发布；封面授权与这一规则一致。

## API 合同

以下路径相对 `/api/v1`。所有私人请求按当前会话鉴权；导航隐藏不能代替服务端鉴权。

| 方法与路径 | 权限与行为 |
| --- | --- |
| GET `/series` | 公开分页；q、state、author_id、limit、cursor；游标绑定筛选与读取范围 |
| GET `/series/{id}` | 当前公开目录，不接受 status=draft 绕过 |
| GET `/me/series` | author / owner 默认仅自己；owner 可显式 scope=site |
| GET `/studio/series/{id}` | 作者本人或 owner；返回 version / 私人章节状态 |
| POST `/series` | author / owner；完整专栏输入，返回 201 |
| PUT `/studio/series/{id}` | 作者本人或 owner；完整替换 + If-Match |
| DELETE `/studio/series/{id}` | 作者本人或 owner；If-Match，软删除专栏，保留文章 |
| GET `/share?type=post\|moment\|phrase\|series&id={id}` | 仅当前公开资源；返回短链、专属分享 URL、embed URL / HTML、原文 URL |
| GET `/users/{id}/follow-state` | 登录用户对该人的关注状态与公开关注开关；不遍历全部关注列表 |

专栏输入示例：

```json
{
  "title": "从零搭建个人博客",
  "description": "从部署到连续写作",
  "cover_media_id": null,
  "status": "published",
  "state": "ongoing",
  "chapter_post_ids": ["10", "18", "21"]
}
```

slug 可选、为空时创建自动生成；当前规范 URL 使用稳定数字 ID，不把 slug 当成已实现的自定义地址。详情最多返回 300 条章节元数据。管理文章选择器分页 20 条，不预取整个文章库。

## 三种分享

| 方式 | 地址 | 行为 |
| --- | --- | --- |
| 短链接 | `/s/{token}` | 每次检查资源仍公开，然后 302 到站内规范地址 |
| 内嵌 HTML | `/embed/{token}` | 无脚本卡片，展示摘要 / 封面 / 原文入口，可复制 iframe HTML |
| 专属分享 | `/share/{token}` | 独立简洁页面，展示摘要和作者，引导跳回站内阅读，不含完整正文 |

目前四类资源都支持这三种方式。分享不是新增阅读权限，也不是私人文件外链。令牌是资源种类 + base36 ID + 分域 HMAC 签名，不接受任意目标地址；生成分享为只读操作，不写数据库、没有后台任务。保留原有加密密钥时链接稳定；轮换该密钥会使旧链接失效，备份恢复必须按现有密钥管理流程执行。

所有分享响应均 `private, no-store`，不存在把已撤回摘要长期缓存的机制。浏览器分享面板关闭会取消在途请求，重新打开再次校验。外部平台已经自行抓取的副本不受本站撤回控制。

只有 `/embed` 允许被外站嵌入；站内其他页面继续禁止 framing。卡片不加载 Vue、会话或业务 JS，只载入独立小 CSS。复制 HTML 使用 sandbox、no-referrer 和安全新窗口原文入口；父站仍可能自行禁止 iframe。嵌入许可由响应的 [CSP frame-ancestors](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors) 控制，iframe 自身的权限参照 [iframe 文档](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)。

## 请求、SEO 与维护

- 专栏列表、章节与文章所属专栏由 SSR 提供，不再由浏览器重复请求正文或目录。
- 分享首次打开 1 次元数据请求；切换三种方式 0 次追加请求。独立摘要 / 嵌入页面不查会话。
- 公开专栏进入 sitemap，分页抓取；草稿、删除项不进入 sitemap。规范地址是 `/series/{id}`。分享摘要 canonical 指向原文，并避免摘要页成为重复索引入口。
- 数据库全量备份包含新增表、约束、索引；封面仍使用现有媒体目录备份。无额外服务、第三方短链依赖或外部队列。
- 个人中心的主页外观和安全按实际任务首次加载；默认 GET 合并同路径在途请求，公开正文由 SSR 提供。更大内容量下可继续优化文章选择器为轻量投影、所属专栏读取和引用卡片批量读取；这些需要实际慢查询和网络录制支持。
